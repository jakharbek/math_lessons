# AGENTS.md — руководство для ИИ-агентов и авторов курса

Проект — интерактивный курс **«Математика по косточкам»** на русском языке: математика для машинного
обучения от функций и производной до градиентного спуска. Каждый урок — веб-страница с формулами,
интерактивными рисунками, задачами, тестом и ИИ-наставником.

Курс — младший брат [«Градиентного бустинга по косточкам»](https://github.com/jakharbek/ml_gradient_boosting):
та же педагогика и тот же бэкенд ИИ-ассистента (`claude-server`), а дизайн — как в блоге
[javharbek.uz](https://javharbek.uz/ru/): Manrope, STIX Two Text, минимализм, светлая и тёмная тема.

Этот файл — **источник истины о правилах проекта**. `CLAUDE.md` импортирует его.

---

## 1. Золотые правила

1. **Язык контента — русский.** Текст, подписи рисунков, сообщения интерфейса — по-русски. Идентификаторы
   в коде — английские. Термин при первом упоминании — с английским оригиналом: «темп обучения (learning rate)».
2. **По косточкам.** От интуиции к строгой формулировке, от целого к частям. Понятие не используется раньше,
   чем объяснено, — или есть явная ссылка на урок, где оно объясняется (`<a data-lesson="2.1"></a>`).
3. **Математика точная.** Определения и теоремы — с условиями; «необходимо» и «достаточно» не путаются;
   упрощение называется упрощением. Каждое число в тексте проверено вычислением.
4. **Числа — по-русски:** десятичная запятая в формулах `$0{,}1$`, координаты через точку с запятой `(1; 2)`,
   минус — `−`. В рисунках это делают `MC.util.fmt` и `MC.util.fixed`.
5. **Без сборщика.** Обычные скрипты (не ES-модули), глобальный объект `MC`; страницы работают и по `http://`,
   и с диска (`file://`). Внешнее — только KaTeX и highlight.js с CDN и шрифты Google Fonts; без них курс работает
   (формулы остаются текстом).
6. **Минимализм блога.** Монохром + один синий акцент, радиус 4px, никаких теней у карточек и рамок «для красоты».
   Новые цвета — только через токены `:root` в `assets/css/course.css` (оба режима темы).

## 3. Урок

### Запись в программе (`assets/js/course.js`)

```js
{
  id: '2.2', status: 'ready', title: 'Производная', short: 'Производная',
  subtitle: 'Мгновенная скорость изменения: от секущей к касательной',
  summary: '…',                 // одна-две фразы для программы на главной
  minutes: 40, level: 2,        // уровень 1–4: начальный … экспертный
  objectives: ['… ($формулы$ можно)'],
  keywords: ['…'],              // для поиска на главной
}
```

Урок без `status: 'ready'` показывается в программе как «скоро». Номер урока — `часть.порядок`;
папка — `lessons/lesson_2_2/`. Тест `course.test.js` проверяет соответствие.

### Страница (`lessons/lesson_X_Y/index.html`)

В файле — только содержание. Шапку, заголовок с целями, оглавление, «урок пройден», соседние уроки и подвал
строит `page.js` по записи в программе.

```html
<!doctype html>
<html lang="ru" data-lesson="2.2">
<head>
  <meta charset="utf-8"><meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
  <title>2.2 Производная — Математика по косточкам</title>
  <link rel="icon" href="../../assets/img/favicon.svg" type="image/svg+xml">
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600&family=STIX+Two+Text:ital,wght@0,400;0,500;1,400&family=JetBrains+Mono:wght@400&display=swap">
  <link rel="stylesheet" href="../../assets/css/course.css">
  <script src="../../assets/js/boot.js" data-root="../../" data-scripts="lesson.js"></script>
</head>
<body><main class="lesson" id="lesson"> …<section id="…"><h2>…</h2>…</section>… </main></body>
</html>
```

Порядок разделов: **Зачем это нужно → Интуиция → Определение → Разбор по косточкам → Пример →
Рисунки и свойства → Теорема с доказательством → Частые ошибки → Задачи → Итоги → Проверь себя**.
Разделы нумеруются автоматически; `class="unnumbered"` — без номера («Итоги», «Проверь себя»).
`#summary` и `#quiz` обязательны.

### Компоненты разметки

| Разметка | Что даёт |
|---|---|
| `<div class="env def" data-name="производная">…</div>` | «Определение 1 · *производная*» — нумеруется сам |
| `env thm` / `env example` | «Теорема N», «Пример N» (нумеруются) |
| `env intuition` / `env note` / `env warn` / `env history` | «Интуиция», «Замечание», «Частая ошибка», «Из истории»; `data-label` — свой заголовок |
| `<div class="eq" id="eq-def">$$…$$</div>` | выключная формула с номером (1), (2)…; `eq nonum` — без номера |
| `<a class="eq-ref" href="#eq-def"></a>` | ссылка на формулу, текст «(2)» подставится |
| `<dl class="legend"><dt>$x$</dt><dd>…</dd></dl>` | расшифровка обозначений под формулой |
| `<details class="proof"><summary>Доказательство</summary><div class="proof-body">…</div></details>` | сворачиваемое доказательство с ∎ |
| `<details class="deeper"><summary>…</summary><div class="deeper-body">…</div></details>` | необязательный блок «Глубже» |
| `<div class="bones"><details class="bone"><summary>…</summary><div class="bone-body">…</div></details></div>` | «Разбор по косточкам», нумерация 1, 1.1 |
| `<div class="exercise" data-stars="2" data-name="…">…<details><summary>Решение</summary><div class="sol">…</div></details></div>` | «Задача N ★★☆» + кнопка ИИ «Подсказка» |
| `<div class="quiz"><script type="application/json">[{"q","options","answer","explain"}]</script></div>` | тест; в JSON `\\` для TeX, `&lt;` вместо `<` |
| `<div data-widget="имя" data-config='{…}'><p class="figcaption">…</p></div>` | интерактивный рисунок из `lesson.js` |
| `<a data-lesson="2.1" data-case="prep"></a>` | ссылка на урок: «урок 2.1 «Предел»»; `data-case="prep"` — «уроке…», `"gen"` — «урока…»; если урок «скоро» — текст с меткой |
| `.table-wrap > table.data`, `.takeaway`, `.lead`, `.term` | таблица, итоги, вводный абзац, термин |

Формулы: `$…$`, `$$…$$`, `\(…\)` (KaTeX; не внутри `<pre>/<code>`). В HTML внутри формул пишите `&lt;`, `&gt;`, `&amp;`.

### Рисунок (`lesson.js`)

```js
MC.widget('secant', (el, cfg) => {
  const fig = MC.fig.shell(el, { kicker: 'Рисунок 1', title: 'От секущей к касательной' });
  const p = new MC.Plot(fig.plot, { width: 720, height: 420, x: [-2.5, 2.5], y: [-1, 6] });
  const h = MC.fig.slider({ label: 'Шаг $h$', min: 0, max: 2, value: 1, oninput: draw });
  fig.controls.append(h.el);
  const ro = MC.fig.readout(fig.readout, [{ key: 'k', label: 'наклон' }]);
  p.axes({ xLabel: 'x', yLabel: 'y' });
  function draw() { p.clear(); p.fn((x) => x * x, 'curve'); /* … */ ro.set('k', MC.util.fmt(2)); }
  draw();
});
```

`MC.Plot`: `axes, fn, path, seg, lineSlope, dot, text, polygon, arrow, contours, handle, toData`.
Классы цвета: `curve` (чернила), `accent` (синий — главное действие/модель), `warm` (оранжевый — второе),
`teal`, `faint`, `dash`, `guide`, `leg`. Цвета берутся из токенов — тема меняется без перерисовки.
`MC.fig`: `shell, slider (map/fmt), seg, check, button, readout, player, rich` (текст с `$…$`).
Ширину графика берите из контейнера (`fig.plot.clientWidth`, 320–720) — так подписи читаются на телефоне.

## 4. ИИ-наставник

Выделил текст → «Спросить ИИ» (или `Alt+I`, или кнопка в шапке) → панель справа. У каждой задачи —
кнопка «Подсказка». Подключается сам на каждой странице урока (`MC.bus 'pageready'`).

* **Бэкенд** — `claude-server` (порт 8137, OpenAI-совместимый `/v1/chat/completions` с SSE поверх `claude -p`,
  вход — `claude login`). Это та же папка, что в курсе бустинга: **правки сервера переносите в оба репозитория**.
  Сайт `https://jakharbek.github.io` разрешён серверу по умолчанию — подходят оба курса.
* **Контекст** (`buildMessages`): системный промпт наставника + урок (номер, часть, цели, разделы), история,
  вопрос с фрагментом и текстом раздела. Формулы KaTeX уходят в TeX. Для задачи цитата — только условие,
  эталонное решение остаётся в тексте раздела (чтобы проверять решение ученика); промпт требует сначала подсказку.
* **Лимит** — весь запрос ≤ 22 000 символов (командная строка Windows). Не увеличивайте без проверки на Windows.
* **Безопасность:** запрос не включает `allow_tools`, `permission_mode`, `cwd`; ответ модели — недоверенные данные,
  показывается через `MC.md` (без `innerHTML`, ссылки только http/https).
* **Хранение:** настройки — `mc:assistant-settings`, диалоги — `mc:assistant:<id урока>`; скриншоты не сохраняются.

## 7. Частые ошибки

* `*/` внутри блочного комментария JS (например, путь `lessons/*/…`) закрывает комментарий.
* В `data-config` — строгий JSON в одинарных кавычках атрибута.
* Скрытая MathML-разметка KaTeX позиционируется абсолютно: контейнер с прокруткой (`.table-wrap`, `.eq`) должен
  быть `position: relative`, иначе на телефоне появится горизонтальная прокрутка страницы.
* `class="no-math"` у корня ответа ассистента — исключение из авто-отрисовки, а не стиль: стиль запасной формулы
  задан только для `span.no-math`.
* `data-scripts` в `boot.js` — список через запятую.
