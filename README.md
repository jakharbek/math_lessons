# Математика по косточкам

Интерактивный курс всей математики — от счёта и дробей до топологии, теории чисел и открытых проблем.
Каждая тема разбирается «по косточкам»: сначала интуиция и пример на числах, затем строгое определение,
теорема с доказательством, живые рисунки, задачи трёх уровней и тест. В каждом уроке работает
**ИИ-наставник**: выделите непонятное место — слово, формулу, абзац — и спросите.

Дизайн — как у блога [javharbek.uz](https://javharbek.uz/ru/): Manrope для текста, STIX Two Text для
математики, светлая и тёмная тема, ничего лишнего. Курс — младший брат
[«Градиентного бустинга по косточкам»](https://github.com/jakharbek/ml_gradient_boosting) и использует
тот же бэкенд ИИ-ассистента.

## Как устроен урок

- **Интуиция → строго → руками → проверка.** Определения, теоремы и примеры нумеруются автоматически,
  формулы — тоже, доказательства сворачиваются, а «Разбор по косточкам» раскрывает формулу слой за слоем.
- **Интерактивные рисунки** на SVG: секущая, которая превращается в касательную; матрица, двигающая всю
  плоскость; градиентный спуск по карте линий уровня. Всё перетаскивается и анимируется.
- **Задачи** ★☆☆ … ★★★ с решениями и **тест** «Проверь себя» с пояснениями.
- **Прогресс** хранится в браузере: отметка «урок пройден» видна в программе, главная кнопка ведёт
  к последнему открытому уроку.

## ИИ-наставник

Выделите текст → «Спросить ИИ» (или <kbd>Alt</kbd>+<kbd>I</kbd>). Наставник получает фрагмент, раздел
и цели урока, формулы — в TeX, и отвечает с формулами. У каждой задачи — кнопка «Подсказка»: наставник
даёт наводящий шаг, а не готовый ответ. К вопросу можно приложить скриншот рисунка.

Работает через Claude Code на вашем компьютере, ключ API не нужен:

```bash
npm install -g @anthropic-ai/claude-code && claude login   # один раз
python tools/serve.py                                       # курс + claude-server
```

или только сервер: `node claude-server/server.js`. Сервер, уже запущенный для курса бустинга, подходит и здесь.
Без сервера курс работает как обычно — панель подскажет, как его запустить. Подробности — в
[claude-server/README.md](claude-server/README.md).

## Локально

Страницы открываются прямо с диска (`index.html`), но удобнее через сервер:

```bash
python tools/serve.py            # http://127.0.0.1:8000
```
