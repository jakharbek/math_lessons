ИИ-наставник

Выделите непонятное — и спросите

В каждом уроке работает наставник на Claude. Он видит выделенный фрагмент, раздел и цели урока, а формулы получает в TeX — поэтому отвечает именно про то место, где вы застряли.

  • выделите слово, формулу или абзац и нажмите «Спросить ИИ» или Alt+I
  • у каждой задачи — кнопка «Подсказка»: наводящий шаг, а не готовый ответ
  • скриншот рисунка можно приложить к вопросу
  • работает через Claude Code на вашем компьютере — без ключей API

Производная — это предел, к которому стремится наклон секущей, когда вторая точка приближается к первой: $f'(x_0) = \lim\limits_{h \to 0} \frac{f(x_0+h)-f(x_0)}{h}$.

Спросить ИИ
НаставникЧислитель — насколько выросла функция, знаменатель — на сколько сдвинулись по оси. Их отношение — средняя скорость на отрезке длиной $h$. Для $f(x) = x^2$ в точке $x_0 = 1$ это $2 + h$: при $h = 0{,}1$ получаем $2{,}1$, при $h = 0{,}01$ — $2{,}01$. Предел — ровно $2$.
