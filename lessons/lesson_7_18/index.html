Зачем это нужно

«$2 + 3 = 3 + 2$» и «$(2 + 3) + 4 = 2 + (3 + 4)$» в школе принимают на веру. В этом параграфе их доказывают — из нескольких аксиом, которые говорят только одно: как прибавить к числу ноль и как прибавить «следующее» число. Всё остальное — ассоциативность (associativity), коммутативность (commutativity), закон сокращения (cancellation law), дистрибутивность (distributivity) — выводится одним и тем же инструментом: математической индукцией (mathematical induction).

Урок идёт по § 2 «Свойства сложения и умножения натуральных чисел» главы четвертой «Основные числовые системы» учебника Л. Я. Куликова «Алгебра и теория чисел» (М.: Высшая школа, 1979), с. 122–131. Каждое предложение параграфа приведено дословно (метка «Цитата» и страница), с указанием источника — в учебных целях, для построчного разбора. Нажмите на предложение — откроется его разбор: смысл каждого слова и символа, обоснование каждого шага доказательства, примеры на числах, из жизни и из программирования, к каждому определению — контрпример, к каждому упражнению — полное решение.

Параграф продолжает : там натуральные числа введены как алгебра $\langle \mathbf{N}, +, \cdot, 0, 1\rangle$ с аксиомами I–VII (аксиомы Пеано), а принцип индукции — как аксиома VII. Слова «алгебра», «моноид», «ассоциативная и коммутативная операция», «нейтральный и регулярный элемент» пришли из главы третьей: , , . Схемы доказательств и кванторы — из и . Следующий параграф — — строит на разности из этого урока отношение «меньше».

Где это встречается за пределами учебника:

  • программирование: рекурсивное определение add(m, 0) = m, add(m, n + 1) = add(m, n) + 1 — это буквально аксиомы сложения; в языках доказательств (Lean, Coq, Agda) теоремы этого параграфа — первые упражнения учебников, и доказываются они той же индукцией;
  • параллельные вычисления: ассоциативность и коммутативность сложения разрешают суммировать массив по кускам, в любом порядке, на тысячах потоков GPU — для целых чисел это строгая теорема этого параграфа (для чисел с плавающей точкой ассоциативность нарушается);
  • машинное обучение: закон сокращения и «нет делителей нуля» (теоремы 2.4, 2.15, 2.16) — то, что делает решение уравнений однозначным; в арифметике по модулю (хеши, криптография, квантование весов) они уже могут не выполняться.

$\mathbf{N}$ (полужирное) — множество натуральных чисел, и у Куликова оно начинается с нуля: $\mathbf{N} = \{0, 1, 2, \ldots\}$. Аксиомы § 1 (с. 119): I — $n + 1 \ne 0$; II — из $m + 1 = n + 1$ следует $m = n$; III — $m + 0 = m$; IV — $m + (n + 1) = (m + n) + 1$; V — $m \cdot 0 = 0$; VI — $m \cdot (n + 1) = m \cdot n + m$; VII — принцип индукции. В доказательствах этого параграфа ссылки идут именно по этой нумерации (хотя в списке на с. 122 аксиомы сложения напечатаны под номерами IV и V — см. разбор). Знак $\rightarrow$ — импликация «если…, то», $\vee$ — «или», $\exists$ — «существует», $\square$ — конец доказательства. Букву «ё» книга не печатает: «трех», «ведет», «Проведем».

§ 2. СВОЙСТВА СЛОЖЕНИЯ И УМНОЖЕНИЯ НАТУРАЛЬНЫХ ЧИСЕЛ

Сложение натуральных чисел удовлетворяет следующим условиям (аксиомам):

Параграф открывается напоминанием: сложение в системе натуральных чисел не «известно из школы», а задано аксиомами из § 1 (). Всё, что мы будем знать о $+$, должно выводиться из двух условий ниже (и общих аксиом I, II, VII о единице и индукции).

Слово «условиям (аксиомам)» подчёркивает двойную роль: для заданной алгебры $\langle \mathbf{N}, +, \cdot, 0, 1\rangle$ это условия, которые проверяют; для теории натуральных чисел — аксиомы, из которых выводят теоремы.

IV. Для каждого $m$ из $\mathbf{N}$ $m + 0 = m$.

Первая аксиома сложения: прибавить ноль — ничего не изменить. На языке главы третьей: $0$ — правый нейтральный элемент для $+$ (). Что $0$ ещё и левый нейтральный ($0 + m = m$), здесь не сказано — это придётся доказать (в доказательстве теоремы 2.3).

«Для каждого $m$ из $\mathbf{N}$» — квантор всеобщности

В символах: $\forall m \in \mathbf{N}\ (m + 0 = m)$. Одно равенство на всё бесконечное множество.

«$m + 0$» — ноль справа

Порядок важен: аксиома говорит о $m + 0$, а не о $0 + m$. Пока коммутативность не доказана, это разные выражения.

В § 1 (с. 119) это условие имеет номер III, а следующее — IV; номера V и VI там у аксиом умножения, и на с. 128 умножение снова задаётся аксиомами «V» и «VI». Значит, здесь правильно «III. Для каждого $m$ из $\mathbf{N}$ $m + 0 = m$» и «IV. Для любых $m$ и $n$ из $\mathbf{N}$ $m + (n + 1) = (m + n) + 1$». Все ссылки «по аксиоме IV» в доказательствах ниже относятся к правилу $m + (n + 1) = (m + n) + 1$ — по нумерации § 1.

(а) На числах. $7 + 0 = 7$, $0 + 0 = 0$.

(б) Из жизни. Положить в копилку ноль монет — сумма в копилке не изменится.

(в) В программировании. База рекурсии: def add(m, n): return m if n == 0 else add(m, n - 1) + 1 — ветка n == 0 и есть эта аксиома.

V. Для любых $m$ и $n$ из $\mathbf{N}$ $m + (n + 1) = (m + n) + 1$.

Вторая аксиома: прибавить «следующее» число — значит прибавить число и потом ещё единицу. Это шаг рекурсии: сумма с $n + 1$ выражается через сумму с $n$.

«$n + 1$» — следующее за $n$

В системе Куликова прибавление единицы играет роль «функции следования» (successor): $n \mapsto n + 1$. Аксиомы I, II говорят, что эта функция не попадает в $0$ и инъективна.

скобки — в чём содержание

Слева сначала считают $n + 1$, потом прибавляют к $m$; справа — сначала $m + n$, потом $+1$. Это частный случай ассоциативности $a + (b + c) = (a + b) + c$ при $c = 1$ — Куликов в § 1 называет условие «слабой формой ассоциативности». Полную ассоциативность докажет теорема 2.1.

По нумерации § 1 это аксиома IV (см. разбор предыдущей аксиомы). В доказательствах ниже она так и цитируется: «по аксиоме IV».

(а) На числах. $4 + 3 = 4 + (2 + 1) = (4 + 2) + 1$: чтобы прибавить $3$, достаточно знать $4 + 2$.

(б) Из жизни. Пройти $n + 1$ шагов от дома — то же, что пройти $n$ шагов и затем ещё один.

(в) В программировании. Ветка else: return add(m, n - 1) + 1. Каждый вызов уменьшает второй аргумент, поэтому рекурсия заканчивается на n == 0.

Эти условия дают возможность для любого фиксированного натурального числа $m$ вычислить значение суммы $m + n$ последовательно для значений $n$, равных $0, 1, 2, \ldots$

Как работают две аксиомы вместе: при фиксированном $m$ первая даёт $m + 0$, вторая из $m + 0$ даёт $m + 1$, из $m + 1$ — $m + 2$ и так далее. Это рекурсивное (индуктивное) определение функции $n \mapsto m + n$: значение в $0$ задано, значение в $n + 1$ выражено через значение в $n$.

Рисунок 1 ниже делает ровно это — по одному шагу на каждое применение аксиомы.

Следовательно, эти условия позволяют найти значение суммы $m + n$ для любых натуральных чисел $m$ и $n$.

Почему «для любых»: множество тех $n$, для которых сумма $m + n$ уже найдена, содержит $0$ и вместе с каждым $n$ содержит $n + 1$. По аксиоме индукции VII такое множество совпадает со всем $\mathbf{N}$.

Аксиомы IV и V (III и IV по § 1) не определяют сложение сами по себе: у Куликова $+$ — операция, данная вместе с алгеброй, а аксиомы её описывают. Но они определяют её однозначно: две операции, удовлетворяющие обеим аксиомам, совпадают (индукцией по $n$). Именно это и выражает слово «следовательно».

Например, пусть $m = 5$ и $n = 3$.

Пример автора: посчитаем $5 + 3$, пользуясь только аксиомами — без «школьного» знания, что ответ $8$.

Используя условия III, IV и V, можно выписать следующую цепочку равенств: $$5 + 0 = 5; 5 + 1 = 6; 5 + 2 = 5 + (1 + 1) = (5 + 1) + 1 = 6 + 1 = 7;$$ $5 + 3 = 5 + (2 + 1) = (5 + 2) + 1 = 7 + 1 = 8$; таким образом, $5 + 3 = 8$.

Разберём каждое звено.

  • $5 + 0 = 5$ — аксиома $m + 0 = m$.
  • $5 + 1 = 6$ — не аксиома, а обозначение: в § 1 цифры введены как имена чисел $1 + 1 = 2$, $(1 + 1) + 1 = 3$, …; значит, $6$ — это по определению $5 + 1$.
  • $5 + 2 = 5 + (1 + 1)$ — потому что $2$ есть $1 + 1$; $= (5 + 1) + 1$ — аксиома $m + (n + 1) = (m + n) + 1$ при $m = 5$, $n = 1$; $= 6 + 1 = 7$ — снова обозначения.
  • $5 + 3 = 5 + (2 + 1) = (5 + 2) + 1$ — та же аксиома при $n = 2$; $= 7 + 1$ — по уже найденному $5 + 2 = 7$; $= 8$ — обозначение.

«Условия III, IV и V» не совпадают ни с одной нумерацией: по § 1 в цепочке использованы аксиомы III ($m + 0 = m$) и IV ($m + (n + 1) = (m + n) + 1$) и десятичные обозначения из § 1, а по списку на с. 122 — «IV и V». Аксиома V § 1 ($m \cdot 0 = 0$) здесь не нужна.

Важно, что каждое следующее звено использует предыдущее ($5 + 2 = 7$ нужно для $5 + 3$). Это и есть «последовательно» из предложения выше.

Сумма $m + n$ по аксиомам. «Шаг» применяет одну аксиому: сначала $m + 0 = m$ (III по § 1), затем $m + (k + 1) = (m + k) + 1$ (IV по § 1) — к ряду точек добавляется одна синяя. «Всё сразу» показывает всю цепочку, «Сначала» — начинает заново. При $m = 5$, $n = 3$ получается цепочка из примера Куликова.

ТЕОРЕМА 2.1. Сложение натуральных чисел ассоциативно, т. е. для любых натуральных $a$, $b$, $c$ $$\text{(1)}\quad a + (b + c) = (a + b) + c.$$

Первая настоящая теорема параграфа: скобки в сумме трёх чисел можно ставить как угодно.

«ассоциативно» — определение из главы третьей

Операция $\top$ ассоциативна, если $a \mathbin{\top} (b \mathbin{\top} c) = (a \mathbin{\top} b) \mathbin{\top} c$ для любых $a, b, c$ (). Формула (1) — это определение для $\top = +$.

«для любых натуральных $a$, $b$, $c$» — три квантора

$\forall a\,\forall b\,\forall c\ (a + (b + c) = (a + b) + c)$. Доказательство будет индукцией лишь по одной переменной $c$, а $a$, $b$ «заморозятся».

чем отличается от аксиомы IV

Аксиома — это (1) только при $c = 1$. Теорема распространяет её на все $c$: индукция «размножает» частный случай.

(а) На числах. $2 + (3 + 4) = 2 + 7 = 9$ и $(2 + 3) + 4 = 5 + 4 = 9$.

(б) Из жизни. Сложить расходы за январь и февраль, а потом прибавить март — то же, что прибавить к январю сумму февраля и марта.

(в) В программировании и ML. Сумма градиентов по мини-батчам: reduce(add, chunks) можно считать деревом на многих потоках, потому что скобки не важны. Для целых чисел это гарантирует теорема 2.1.

Сложение чисел с плавающей точкой: в типе double (0.1 + 0.2) + 0.3 даёт 0.6000000000000001, а 0.1 + (0.2 + 0.3) — 0.6; ещё нагляднее $(10^{16} + 1) + 1 = 10^{16}$ (каждая единица теряется при округлении), а $10^{16} + (1 + 1) = 10^{16} + 2$. Вычитание натуральных чисел тоже не ассоциативно: $(5 - 3) - 1 = 1$, а $5 - (3 - 1) = 3$.

Доказательство. Зафиксируем произвольные натуральные числа $a$ и $b$.

Приём «фиксации»: $a$ и $b$ — любые, но дальше не меняются. Индукция будет идти только по $c$. В конце (последнее предложение доказательства) мы вспомним, что $a$, $b$ были произвольными, и получим утверждение для всех троек — это правило обобщения из логики ().

Тогда формула (1) определяет предикат от одной свободной переменной $c$, обозначим его $A(c)$.

При закреплённых $a$, $b$ равенство $a + (b + c) = (a + b) + c$ становится предикатом от $c$ (): при одних $c$ оно может быть истинным, при других — ложным. Например, при $a = 2$, $b = 3$: $A(c)$ — «$2 + (3 + c) = 5 + c$». Цель — доказать $\forall c\, A(c)$.

Доказательство проводится индукцией по натуральной переменной $c$.

План по принципу индукции (§ 1, ): (1) базис — доказать $A(0)$; (2) шаг — доказать, что из $A(n)$ следует $A(n + 1)$ для любого $n$. Тогда множество $\{c : A(c)\}$ содержит $0$, замкнуто относительно $+1$ и по аксиоме VII равно $\mathbf{N}$.

Почему индукция именно по $c$: аксиомы сложения «раскрывают» второе слагаемое ($m + (n + 1)$), а в (1) переменная $c$ стоит вторым слагаемым в обеих частях.

Базис индукции: $A(0)$ истинно, поскольку верно равенство $a + (b + 0) = (a + b) + 0$.

Проверим это равенство аксиомой нуля дважды: слева $b + 0 = b$, значит $a + (b + 0) = a + b$; справа $(a + b) + 0 = a + b$ (та же аксиома при $m = a + b$). Обе части равны $a + b$.

Индукционный шаг. Предположим, что для некоторого натурального $n$ истинно $A(n)$, т. е. верна формула $$a + (b + n) = (a + b) + n,$$ и докажем, что тогда истинно $A(n + 1)$, т. е. верна формула $$a + (b + (n + 1)) = (a + b) + (n + 1).$$

Шаг индукции — импликация $A(n) \rightarrow A(n + 1)$. Её доказывают обычным путём: считают $A(n)$ истинным (индуктивное предположение, inductive hypothesis) и выводят $A(n + 1)$. Обе формулы — просто (1) с $c = n$ и $c = n + 1$.

Мы не предполагаем то, что доказываем: $A(n)$ — для одного, уже «пройденного» $n$, а вывод — о следующем числе. Порочный круг был бы, если бы мы предположили $\forall c\, A(c)$.

В самом деле, $$\begin{aligned} a + (b + (n + 1)) &= a + ((b + n) + 1) && \text{(по аксиоме IV)};\\ &= (a + (b + n)) + 1 && \text{(по аксиоме IV)};\\ &= ((a + b) + n) + 1 && \text{(по индуктивному предположению)};\\ &= (a + b) + (n + 1) && \text{(по аксиоме IV)}. \end{aligned}$$

Каждая строка — одно применение правила $m + (k + 1) = (m + k) + 1$ (аксиома IV по § 1) или предположения.

  1. Внутри скобки: $b + (n + 1) = (b + n) + 1$ — аксиома при $m = b$, $k = n$.
  2. $a + ((b + n) + 1) = (a + (b + n)) + 1$ — та же аксиома при $m = a$, $k = b + n$: «единица выносится» за скобку.
  3. $a + (b + n)$ заменяем на $(a + b) + n$ — это $A(n)$.
  4. $((a + b) + n) + 1 = (a + b) + (n + 1)$ — аксиома, прочитанная справа налево, при $m = a + b$, $k = n$.

Получили $A(n + 1)$. Шаг доказан.

Ссылки «по аксиоме IV» верны по нумерации § 1 ($m + (n + 1) = (m + n) + 1$); по списку на с. 122 это была бы «аксиома V».

Согласно принципу индукции, предикат $A(c)$ истинен для любого натурального $c$.

Базис и шаг доказаны — по аксиоме VII $A(c)$ верно при всех $c$. Заметим: это пока для закреплённых $a$, $b$.

Поскольку при доказательстве фиксировались произвольные $a$ и $b$, то формула (1) верна для любых натуральных $a$ и $b$. $\square$

Обобщение: о $a$ и $b$ ничего, кроме натуральности, не использовалось, значит, рассуждение годится для любых. Итог: $\forall a\,\forall b\,\forall c\ (a + (b + c) = (a + b) + c)$. Знак $\square$ — конец доказательства.

Следствие для практики: в сумме $a + b + c$ скобки можно не писать. Для четырёх и более слагаемых это тоже верно (общий закон ассоциативности, см. ).

ОПРЕДЕЛЕНИЕ. Алгебра $\langle \mathbf{N}, +, 0\rangle$ называется аддитивным моноидом натуральных чисел.

Имя для того, что мы уже знаем о сложении: операция ассоциативна (теорема 2.1), и есть нейтральный элемент $0$.

«Алгебра $\langle \mathbf{N}, +, 0\rangle$»

Множество $\mathbf{N}$ с бинарной операцией $+$ и нульместной операцией «выделить $0$» — алгебра типа $(2, 0)$ ().

«моноидом»

Моноид — множество с ассоциативной операцией и нейтральным элементом. Ассоциативность — теорема 2.1. Нейтральность $0$: справа — аксиома $m + 0 = m$, слева — $0 + m = m$ докажется в теореме 2.3; строго говоря, полная нейтральность установлена только там.

«аддитивным»

Операция записана как сложение (аддитивная форма записи из § 1 главы третьей). Ниже будет и «мультипликативный» моноид $\langle \mathbf{N}, \cdot, 1\rangle$.

(а) На числах. $\langle \mathbf{N}, +, 0\rangle$; также $\langle \mathbf{N}, \max, 0\rangle$ — $\max$ ассоциативна, $\max(0, a) = a$.

(б) Из жизни. Склеивание отрезков пути: путь «никуда» — нейтральный элемент.

(в) В программировании. Строки с конкатенацией и пустой строкой "" — моноид; это ровно то, что нужно функции reduce с начальным значением.

$\langle \mathbf{N} \setminus \{0\}, +\rangle$ (без нуля) — ассоциативна, но нейтрального элемента нет: моноидом не является. $\langle \mathbf{Z}, -, 0\rangle$ — $0$ только правый нейтральный, и вычитание не ассоциативно.

Группой $\langle \mathbf{N}, +, 0\rangle$ не является: у $1$ нет противоположного в $\mathbf{N}$ ($1 + x = 0$ невозможно по аксиоме I и коммутативности). Это исправит переход к целым числам ().

ТЕОРЕМА 2.6. Для любого натурального числа $a$ либо $a = 0$, либо существует такое натуральное число $b$, что $a = b + 1$.

Дизъюнкция двух случаев: $a = 0$ или $\exists b\,(a = b + 1)$. Одновременно они не выполняются (аксиома I: $b + 1 \ne 0$), так что «либо… либо» здесь даже исключающее.

У числа $0$ предшественника нет — поэтому в теореме и стоит «либо $a = 0$». А вот что бывает без аксиомы индукции. Добавим к $\mathbf{N}$ новый элемент $\omega$ и положим $\omega + 1 = \omega$. Аксиомы I и II для «$+1$» по-прежнему верны ($\omega + 1 \ne 0$; из $m + 1 = n + 1$ следует $m = n$ и для пар с $\omega$). Теорема 2.6 формально выполняется ($\omega = \omega + 1$), но «предшественник» $\omega$ — оно само, и спуск $\omega, \omega, \omega, \ldots$ никогда не доходит до нуля. Нарушена аксиома VII: подмножество $\mathbf{N}$ содержит $0$, замкнуто относительно $+1$, но не совпадает со всем множеством. Именно аксиома VII гарантирует, что каждое число получается из $0$ конечным числом шагов «$+1$».

Доказательство. Рассмотрим формулу $$A(a)\colon\ (a = 0) \vee \exists b\,(a = b + 1).$$

Записываем утверждение как предикат от $a$, чтобы применить индукцию. Свободная переменная — $a$; $b$ связана квантором $\exists$.

Доказательство этой формулы проводится индукцией по $a$.

Обычная схема: базис $A(0)$, шаг $A(n) \rightarrow A(n + 1)$.

Очевидно, формула верна при $a = 0$.

При $a = 0$ истинен первый член дизъюнкции ($0 = 0$), значит, истинна вся дизъюнкция.

Предположим, что для некоторого натурального числа $n$ верна формула $$A(n)\colon\ (n = 0) \vee \exists b\,(n = b + 1).$$

Индуктивное предположение. Любопытно, что оно не понадобится: шаг доказывается без него.

Надо показать, что верна формула $$A(n + 1)\colon\ (n + 1 = 0) \vee \exists b\,(n + 1 = b + 1).$$

Цель шага. Первый член дизъюнкции ложен по аксиоме I, так что всё держится на втором.

Эта формула действительно верна, так как второй член дизъюнкции — истинная формула (при $b = n$, $n + 1 = b + 1$).

Свидетель существования — само $n$: при $b = n$ равенство $n + 1 = b + 1$ очевидно. Значит, $\exists b\,(n + 1 = b + 1)$ истинно, и дизъюнкция истинна.

Предположение $A(n)$ не использовалось. Такая индукция по сути — разбор случаев «$a = 0$» и «$a$ есть $n + 1$»; аксиома индукции нужна, чтобы гарантировать, что других случаев нет.

Согласно принципу индукции, формула $A(a)$ верна для любого натурального $a$. $\square$

Аксиома VII. Теорема 2.6 доказана.

СЛЕДСТВИЕ 2.7. Для любых натуральных $a$ и $b$, если $a \ne 0$ или $b \ne 0$, то $a + b \ne 0$.

Сумма равна нулю, только если оба слагаемых нули (в эквивалентной форме — следствие 2.8). В $\mathbf{N}$ нет «отрицательных», которые могли бы компенсировать положительное слагаемое.

«$a \ne 0$ или $b \ne 0$»

Хотя бы одно слагаемое ненулевое. Достаточно разобрать случай $b \ne 0$: второй сводится к нему коммутативностью.

(а) На числах. $0 + 3 = 3 \ne 0$.

(б) Из жизни. Если хотя бы в одном ящике что-то есть, на складе в сумме не пусто.

(в) В ML. Сумма неотрицательных штрафов (регуляризаторов) равна нулю только тогда, когда каждый из них равен нулю.

В $\mathbf{Z}$: $3 + (-3) = 0$ при $3 \ne 0$. По модулю $5$: $2 + 3 \equiv 0$.

Доказательство. Предположим, что $b \ne 0$.

Разбираем один случай. Случай $a \ne 0$ Куликов не пишет: он сводится к этому, так как $a + b = b + a$ (теорема 2.3) — достаточно поменять буквы.

Тогда, по теореме 2.6, существует такое натуральное $c$, что $b = c + 1$.

$b \ne 0$, значит, по теореме 2.6 у $b$ есть предшественник $c$.

В силу аксиомы IV $$a + b = a + (c + 1) = (a + c) + 1.$$

Подставили $b = c + 1$ и «вынесли единицу» по аксиоме $m + (n + 1) = (m + n) + 1$ (IV по § 1).

По аксиоме I, $(a + c) + 1 \ne 0$; следовательно, $a + b \ne 0$. $\square$

Аксиома I: никакое число вида $n + 1$ не равно нулю; здесь $n = a + c$.

СЛЕДСТВИЕ 2.8. Для любых натуральных $a$ и $b$, если $a + b = 0$, то $a = 0$ и $b = 0$.

Контрапозиция следствия 2.7: «если $a \ne 0$ или $b \ne 0$, то $a + b \ne 0$» равносильно «если $a + b = 0$, то $a = 0$ и $b = 0$» (закон де Моргана: отрицание «или» — это «и», ). Поэтому доказательства в книге нет.

(а) На числах. Решения уравнения $x + y = 0$ в $\mathbf{N}$: только $x = y = 0$.

(б) Из жизни. Если на двух счетах вместе ноль, а долгов не бывает, то на каждом ноль.

(в) В программировании. len(a) + len(b) == 0 ⇔ оба списка пусты.

В $\mathbf{Z}$: $2 + (-2) = 0$, но $2 \ne 0$.

ТЕОРЕМА 2.9. Для любых натуральных $a$ и $b$ выполняется одно и только одно из трех условий: ($\alpha$) $a = b$; ($\beta$) $a + k = b$ (для некоторого $k \in \mathbf{N} \setminus \{0\}$); ($\gamma$) $a = b + m$ (для некоторого $m \in \mathbf{N} \setminus \{0\}$).

Закон трихотомии (trichotomy): два натуральных числа либо равны, либо первое «меньше» (к нему надо прибавить ненулевое $k$, чтобы получить второе), либо «больше». Слов «меньше/больше» ещё нет — их введёт § 3 () как раз через ($\beta$) и ($\gamma$).

«одно и только одно» — две части

«Хотя бы одно» (существование) и «не более одного» (взаимное исключение). Доказательство так и разделится.

«$k \in \mathbf{N} \setminus \{0\}$»

Ненулевое натуральное. Без условия $k \ne 0$ условия ($\alpha$) и ($\beta$) пересекались бы ($k = 0$).

(а) На числах. $a = 3$, $b = 7$: ($\beta$) с $k = 4$. $a = 7$, $b = 3$: ($\gamma$) с $m = 4$. $a = b = 5$: ($\alpha$).

(б) Из жизни. Две очереди: длины равны, или в первой надо добавить людей, чтобы сравняться, или во второй.

(в) В программировании. Функция сравнения cmp(a, b) возвращает ровно одно из $-1$, $0$, $1$ — сортировки опираются на то, что для чисел это корректно.

Для пар чисел с покомпонентным сложением: $a = (1, 0)$, $b = (0, 1)$ — ни $a = b$, ни $a + k = b$, ни $a = b + m$ при $k, m$ из $\mathbf{N}^2$ не выполняется. Множества по включению тоже не трихотомичны.

Доказательство. Из следствия 2.5 вытекает, что не может выполняться более чем одно из трех условий.

Первая часть — «не более одного». Её обоснование — следующие три предложения, по одному на каждую пару условий.

В самом деле, если бы выполнялись условия ($\alpha$) и ($\beta$), то $a = a + k$ и $k \ne 0$, что невозможно по следствию 2.5.

Из $a = b$ и $a + k = b$ получаем $a + k = a$ — противоречие со следствием 2.5 ($k \ne 0$).

Если бы выполнялись условия ($\alpha$) и ($\gamma$), то $b = b + m$ и $m \ne 0$, что невозможно.

Из $a = b$ и $a = b + m$ получаем $b = b + m$ с $m \ne 0$ — снова следствие 2.5.

Если бы выполнялись условия ($\beta$) и ($\gamma$), то $a = a + (k + m)$ и $k + m \ne 0$, что также противоречит следствию 2.5.

Подставим $b = a + k$ в $a = b + m$: $a = (a + k) + m = a + (k + m)$ — ассоциативность (теорема 2.1). А $k + m \ne 0$ по следствию 2.7, так как $k \ne 0$. Противоречие со следствием 2.5.

Теперь покажем, что выполняется хотя бы одно из условий ($\alpha$), ($\beta$), ($\gamma$).

Вторая часть — существование. Она потребует индукции.

Фиксируем произвольное натуральное число $a$ и обозначим через $A(b)$ дизъюнкцию условий ($\alpha$), ($\beta$), ($\gamma$).

$A(b)$: «$a = b$, или $a + k = b$ при некотором $k \ne 0$, или $a = b + m$ при некотором $m \ne 0$». Индукция по $b$.

Докажем индукцией по $b$ верность формулы $A(b)$.

Базис — $b = 0$, шаг — от $n$ к $n + 1$.

Верна формула $A(0)$.

Утверждение базиса; обоснование — в следующих трёх предложениях.

В самом деле, если $b = 0$, то либо $a = 0$, либо $a \ne 0$.

Закон исключённого третьего: разбор двух случаев.

Если $a \ne 0$, то $a = 0 + m$, где $m = a \ne 0$.

$0 + a = a$ — левая нейтральность нуля, доказанная внутри теоремы 2.3. Значит, выполняется ($\gamma$) с $m = a$. (Случай $a = 0$ — это ($\alpha$).)

Следовательно, при $b = 0$ выполняется условие ($\alpha$) или условие ($\gamma$).

Базис доказан. Заметим, что ($\beta$) при $b = 0$ невозможно — это следствие 2.8.

Предположим, что для некоторого числа $n$ верна формула $$A(n)\colon\ (a = n) \vee (a + k = n \text{ для некоторого } k \in \mathbf{N} \setminus \{0\} \vee (a = n + m \text{ для некоторого } m \in \mathbf{N} \setminus \{0\}),$$ и покажем, что тогда верна формула $A(n + 1)$.

Индуктивное предположение — дизъюнкция трёх случаев для $b = n$. Шаг будет разбором этих трёх случаев.

Скобки не сбалансированы: после «$\mathbf{N} \setminus \{0\}$» во втором члене не закрыта скобка. Правильно: $(a = n) \vee (a + k = n \text{ для некоторого } k \in \mathbf{N} \setminus \{0\}) \vee (a = n + m \text{ для некоторого } m \in \mathbf{N} \setminus \{0\})$. Знак «$=$» в книге повторён при переносе строки — так принято в русской типографике; в цитате он дан один раз.

В самом деле, если $a = n$, то $a + 1 = b + 1$, — выполняется условие ($\beta$).

Случай ($\alpha$) для $n$: $a = n$, тогда $a + 1 = n + 1$, т. е. для $b = n + 1$ выполняется ($\beta$) с $k = 1 \ne 0$.

Напечатано «$a + 1 = b + 1$»; должно быть «$a + 1 = n + 1$» (здесь $b$ — это $n + 1$, и равенство $a + 1 = (n + 1) + 1$ было бы неверно).

Если $a + k = n$, $a + (k + 1) = n + 1$, выполняется условие ($\beta$).

Случай ($\beta$) для $n$: из $a + k = n$ по аксиоме IV $a + (k + 1) = (a + k) + 1 = n + 1$. Значит, для $n + 1$ выполняется ($\beta$) с $k + 1 \ne 0$ (аксиома I). В предложении опущено «то»: «если $a + k = n$, то $a + (k + 1) = n + 1$».

Если же $a = n + m$, то $a + 1 = (n + 1) + m$ и $m \in \mathbf{N} \setminus \{0\}$.

Случай ($\gamma$) для $n$. $a + 1 = (n + m) + 1 = n + (m + 1) = (n + 1) + m$ — аксиома IV и лемма 2.2. Но цель — сравнить $a$ (а не $a + 1$) с $n + 1$: отсюда разбор $m = 1$ и $m \ne 1$.

В этом случае если $m = 1$, то $a + 1 = (n + 1) + 1$ и, по аксиоме II, $a = n + 1$, — выполняется условие ($\alpha$).

При $m = 1$: $a + 1 = (n + 1) + 1$, аксиома II сокращает единицу: $a = n + 1 = b$. Это ($\alpha$). (В книге знак «$=$» при переносе повторён: «$a + 1 = {}$ / $= (n + 1) + 1$».)

Так как $m \ne 0$, то, по теореме 2.6, существует $k \ne 0$ такое, что $m = k + 1$.

Теорема 2.6: $m \ne 0$, значит, $m = k + 1$ для некоторого $k$.

Теорема 2.6 даёт просто $k$, а не «$k \ne 0$»: при $m = 1$ получится $k = 0$. Правильно: «существует $k$ такое, что $m = k + 1$». То, что $k \ne 0$ при $m \ne 1$, сказано в следующем предложении — оно и нужно.

Если $m \ne 1$, то $k \ne 0$, и из равенства $a + 1 = (n + 1) + (k + 1) = ((n + 1) + k) + 1$ по аксиоме II получаем $a = (n + 1) + k$, $k \ne 0$, — выполняется условие ($\gamma$).

$m \ne 1$ и $m = k + 1$ дают $k \ne 0$ (иначе $m = 0 + 1 = 1$). Дальше: $a + 1 = (n + 1) + (k + 1) = ((n + 1) + k) + 1$ — аксиома IV; аксиома II сокращает единицу: $a = (n + 1) + k$ с $k \ne 0$. Это ($\gamma$) для $b = n + 1$ (роль $m$ играет $k$).

Итак, в любом случае верна формула $A(n + 1)$.

Разобраны все три ветви $A(n)$ — шаг индукции доказан.

Согласно принципу индукции, формула $A(b)$ верна для любого натурального $b$.

Аксиома VII.

Поскольку $a$ фиксировалось произвольно, то утверждение теоремы верно для любых натуральных $a$ и $b$. $\square$

Обобщение по $a$. Трихотомия доказана: «хотя бы одно» — индукцией, «не более одного» — следствием 2.5.

ОПРЕДЕЛЕНИЕ. Разностью двух натуральных чисел $a$ и $b$ называется такое натуральное число $k$, что $b + k = a$.

Вычитание определяется через сложение: $a - b$ — это то, что нужно прибавить к $b$, чтобы получить $a$.

«натуральное число $k$»

Разность ищут только в $\mathbf{N}$. Поэтому она существует не всегда: для $a = 3$, $b = 5$ уравнение $5 + k = 3$ в $\mathbf{N}$ решений не имеет.

«$b + k = a$» — порядок букв

Уменьшаемое $a$, вычитаемое $b$, разность $k$. Равенство $b + k = a$ — «проверка вычитания сложением» из начальной школы.

«такое… что» — пока без единственности

Определение не утверждает, что $k$ один; единственность докажут два предложения ниже, и только после этого законно писать $a - b$.

(а) На числах. Разность $9$ и $4$ — число $5$, так как $4 + 5 = 9$; разность $6$ и $6$ — $0$.

(б) Из жизни. Сдача: сколько добавить к цене, чтобы получить уплаченную сумму.

(в) В программировании. Беззнаковые целые: uint 3 - 5 в C даёт не «ошибку», а $2^{32} - 2$ — именно потому, что разности в $\mathbf{N}$ нет и компьютер считает по модулю.

Для $a = 2$, $b = 7$ разности нет: $7 + k = 2$ невозможно — для пары $2, 7$ выполняется условие ($\beta$) теоремы 2.9 ($2 + 5 = 7$), а значит, ($\gamma$) и ($\alpha$) исключены. Число $k = 5$ — не разность $2$ и $7$ (это разность $7$ и $2$): $7 + 5 = 12 \ne 2$. «Модульная разность» $(2 - 7) \bmod 10 = 5$ тоже не разность в смысле определения: $7 + 5 \ne 2$ в $\mathbf{N}$.

Из теоремы 2.9 следует, что разность двух натуральных чисел $a$ и $b$ существует в том случае, когда выполнено условие ($\alpha$) (при этом $k = 0$) или ($\gamma$).

По трихотомии: ($\alpha$) $a = b$ — тогда $b + 0 = a$, разность $0$; ($\gamma$) $a = b + m$ — разность $m$. Случаи ($\alpha$) и ($\gamma$) вместе — это «$a \geqslant b$» в терминах следующего урока.

В случае выполнения условия ($\beta$) разность чисел $a$ и $b$ не существует.

Если $a + k = b$ с $k \ne 0$ и при этом $b + x = a$, то $a = (a + k) + x = a + (k + x)$, а $k + x \ne 0$ (следствие 2.7) — противоречие со следствием 2.5. Это «$a < b$»: из меньшего большее не вычитается.

Легко показать, что если разность чисел $a$ и $b$ существует, то она единственна.

Утверждение, обоснование которого — следующее предложение.

В самом деле, если $b + k = a$ и $b + m = a$, то $b + k = b + m$, откуда, по закону сокращения для сложения, следует, что $k = m$.

Две разности $k$ и $m$ дают $b + k = b + m$. Закон сокращения (теорема 2.4) сформулирован для правого слагаемого: $a + c = b + c \Rightarrow a = b$. Здесь общее слагаемое слева, поэтому сначала коммутативность: $k + b = m + b$, затем сокращение: $k = m$.

Единственное натуральное число, являющееся разностью чисел $a$ и $b$, обозначают $a - b$.

Обозначение законно только после доказательства единственности: запись $a - b$ должна называть одно число. И только когда разность существует: $3 - 5$ в $\mathbf{N}$ не определено — вычитание здесь частичная операция ().

(б) Из жизни. Если $c$ одинаковых пачек дают столько же листов, сколько $c$ других одинаковых пачек, то в пачках поровну.

(в) В программировании. Нормировка: a * scale == b * scale с scale != 0 на целых без переполнения даёт a == b; по модулю $2^{32}$ это неверно для чётного scale.

По модулю $6$: $1 \cdot 2 \equiv 4 \cdot 2$ ($2 \equiv 8$), $2 \not\equiv 0$, но $1 \not\equiv 4$. Сокращение на делитель нуля невозможно.

Доказательство. По условию, $$\text{(1)}\quad ac = bc,\ c \ne 0.$$

Записываем данные. Доказательство — от противного.

Допустим, что $a \ne b$.

Предположение противного (): цель — получить противоречие.

По теореме 2.8, либо существует такое $k$, что $a + k = b$ и $k \ne 0$, либо существует такое $m$, что $a = b + m$ и $m \ne 0$.

Трихотомия: при $a \ne b$ остаются случаи ($\beta$) и ($\gamma$).

Напечатано «по теореме 2.8»; это теорема 2.9 (трихотомия). Под номером 2.8 в параграфе — следствие о сумме, равной нулю.

В первом случае $bc = ac + kc$ и в силу (1), $bc = bc + kc$, что (по следствию 2.5) невозможно, так как $k \ne 0$, $c \ne 0$ и (по теореме 2.15) $kc \ne 0$.

$bc = (a + k)c = ac + kc$ — правая дистрибутивность (2.10). По (1) $ac = bc$, поэтому $bc = bc + kc$. Но $kc \ne 0$ (теорема 2.15 в исправленном виде: $k \ne 0$, $c \ne 0$), а по следствию 2.5 прибавление ненулевого числа меняет число. Противоречие.

Во втором случае аналогичные рассуждения показывают, что допущение $a \ne b$ ведет к противоречию. $\square$

Восполним: $a = b + m$, $m \ne 0$ — тогда $ac = bc + mc$, по (1) $ac = ac + mc$, $mc \ne 0$ — противоречие со следствием 2.5. Значит, $a = b$.

Упражнения

Упражнения

1. Докажите формулы:

Пять тождеств для сумм — все доказываются индукцией по $n$ по одной схеме: проверить базис, затем к обеим частям формулы для $n$ прибавить следующее слагаемое и привести правую часть к формуле для $n + 1$. Деление «$/6$», «$/3$» понимается так: правая часть — натуральное число, которое при умножении на $6$ (на $3$) даёт произведение в числителе; поэтому удобно доказывать формулы, умноженные на знаменатель. Все пять формул проверены вычислением для $n = 0, \ldots, 11$.

(a) $1 + 3 + 5 + \ldots + (2n + 1) = (n + 1)^2$;

Смысл. Сумма первых $n + 1$ нечётных чисел — квадрат: $1 = 1^2$, $1 + 3 = 2^2$, $1 + 3 + 5 = 3^2$.

Базис $n = 0$: слева одно слагаемое $1$, справа $(0 + 1)^2 = 1$.

Шаг. Пусть $1 + 3 + \ldots + (2n + 1) = (n + 1)^2$. Прибавим следующее нечётное $2(n + 1) + 1 = 2n + 3$: $(n + 1)^2 + 2n + 3 = n^2 + 4n + 4 = (n + 2)^2$ — это формула для $n + 1$. $\square$

Картинка. Квадрат $(n + 1) \times (n + 1)$ из точек дополняется до $(n + 2) \times (n + 2)$ «уголком» из $2n + 3$ точек.

(b) $1^2 + 2^2 + \ldots + n^2 = n(n + 1)(2n + 1)/6$;

Базис $n = 1$: $1 = 1 \cdot 2 \cdot 3 / 6$. (При $n = 0$ обе части равны $0$, если пустую сумму считать нулём.)

Шаг. Докажем $6(1^2 + \ldots + n^2) = n(n + 1)(2n + 1)$. Прибавим $6(n + 1)^2$: $n(n + 1)(2n + 1) + 6(n + 1)^2 = (n + 1)(2n^2 + n + 6n + 6) = (n + 1)(2n^2 + 7n + 6) = (n + 1)(n + 2)(2n + 3)$ — формула для $n + 1$, так как $2(n + 1) + 1 = 2n + 3$. $\square$

Проверка. $n = 4$: $1 + 4 + 9 + 16 = 30 = 4 \cdot 5 \cdot 9 / 6$.

(c) $1 \cdot 2 + 2 \cdot 3 + \ldots + (n - 1)n = (n - 1)n(n + 1)/3$ для $n > 1$;

Базис $n = 2$: слева $1 \cdot 2 = 2$, справа $1 \cdot 2 \cdot 3 / 3 = 2$. Условие $n > 1$ нужно, чтобы в сумме было хотя бы одно слагаемое (при $n = 1$ сумма слева пуста).

Шаг. Прибавим следующее слагаемое $n(n + 1)$: $\frac{(n - 1)n(n + 1)}{3} + n(n + 1) = \frac{n(n + 1)(n - 1 + 3)}{3} = \frac{n(n + 1)(n + 2)}{3}$ — формула для $n + 1$. $\square$

Проверка. $n = 4$: $2 + 6 + 12 = 20 = 3 \cdot 4 \cdot 5 / 3$.

(d) $(1 + 2 + \ldots + n)^2 = 1^3 + 2^3 + \ldots + n^3$;

Обозначим $S_n = 1 + 2 + \ldots + n = n(n + 1)/2$ (упражнение 1 § 1, ).

Базис $n = 1$: $1^2 = 1^3$.

Шаг. $S_{n + 1}^2 = (S_n + (n + 1))^2 = S_n^2 + 2 S_n (n + 1) + (n + 1)^2 = S_n^2 + n(n + 1)^2 + (n + 1)^2 = S_n^2 + (n + 1)^3$. По предположению $S_n^2 = 1^3 + \ldots + n^3$, значит, $S_{n + 1}^2 = 1^3 + \ldots + (n + 1)^3$. $\square$

Проверка. $n = 4$: $(1 + 2 + 3 + 4)^2 = 100 = 1 + 8 + 27 + 64$.

(e) $1^2 + 3^2 + \ldots + (2n - 1)^2 = n(2n - 1)(2n + 1)/3$.

Базис $n = 1$: $1 = 1 \cdot 1 \cdot 3 / 3$.

Шаг. Прибавим $(2n + 1)^2$: $\frac{n(2n - 1)(2n + 1)}{3} + (2n + 1)^2 = \frac{(2n + 1)(2n^2 - n + 6n + 3)}{3} = \frac{(2n + 1)(2n^2 + 5n + 3)}{3} = \frac{(n + 1)(2n + 1)(2n + 3)}{3}$, а это $\frac{(n + 1)(2(n + 1) - 1)(2(n + 1) + 1)}{3}$. $\square$

Проверка. $n = 3$: $1 + 9 + 25 = 35 = 3 \cdot 5 \cdot 7 / 3$.

2. Докажите, что число $C_n^k$ подмножеств из $k$ элементов множества из $n$ элементов $(1 \leqslant k \leqslant n)$ выражается формулой $$C_n^k = \frac{n(n - 1) \ldots (n - k + 1)}{1 \cdot 2 \ldots k}.$$

$C_n^k$ — число сочетаний (binomial coefficient, $\binom{n}{k}$).

Решение. Посчитаем двумя способами число $P$ упорядоченных наборов $\langle x_1, \ldots, x_k\rangle$ из $k$ различных элементов $n$-элементного множества $M$.

  1. Напрямую: $x_1$ выбирается $n$ способами, $x_2$ — $n - 1$, …, $x_k$ — $n - k + 1$. Строго: такой набор — инъекция $\{1, \ldots, k\} \to M$, и их число $n(n - 1) \ldots (n - k + 1)$ (упражнение 3 (a) § 1, ).
  2. Через подмножества: каждое $k$-элементное подмножество упорядочивается $k(k - 1) \ldots 1 = 1 \cdot 2 \ldots k$ способами (то же упражнение при $n = k$), а разные подмножества дают разные наборы. Значит, $P = C_n^k \cdot (1 \cdot 2 \ldots k)$.

Приравнивая, получаем формулу. $\square$ Пример: $C_5^2 = \frac{5 \cdot 4}{1 \cdot 2} = 10$ — двухэлементных подмножеств у $\{1, 2, 3, 4, 5\}$ десять.

Другой путь — индукцией по $n$ с помощью упражнения 3.

3. Докажите, что $C_{n+1}^k = C_n^k + C_n^{k-1}$ для $n \geqslant k > 1$.

Комбинаторно. Пусть $M$ — множество из $n + 1$ элементов, $x \in M$. $k$-элементные подмножества $M$ делятся на два непересекающихся класса: не содержащие $x$ — это $k$-подмножества $M \setminus \{x\}$, их $C_n^k$; содержащие $x$ — они взаимно однозначно соответствуют $(k - 1)$-подмножествам $M \setminus \{x\}$ (выбросить $x$), их $C_n^{k - 1}$. Условие $n \geqslant k > 1$ гарантирует, что оба числа определены формулой упражнения 2 ($1 \leqslant k - 1$, $k \leqslant n$). $\square$

Алгебраически (по формуле упражнения 2): $C_n^k + C_n^{k - 1} = \frac{n!}{k!(n - k)!} + \frac{n!}{(k - 1)!(n - k + 1)!} = \frac{n!\,(n - k + 1 + k)}{k!\,(n - k + 1)!} = C_{n + 1}^k$.

Проверка. $C_5^2 = 10 = C_4^2 + C_4^1 = 6 + 4$. Это правило треугольника Паскаля. (Равенство верно и при $k = 1$, если положить $C_n^0 = 1$.)

4. Докажите, что для любого натурального $n > 1$ $$(x + 1)^n = x^n + C_n^1 x^{n-1} + C_n^2 x^{n-2} + \ldots + C_n^n.$$

Бином Ньютона (binomial theorem) при $y = 1$.

Базис $n = 2$: $(x + 1)^2 = x^2 + 2x + 1$, и $C_2^1 = 2$, $C_2^2 = 1$.

Шаг. Пусть формула верна для $n$. Тогда $(x + 1)^{n + 1} = (x + 1)^n x + (x + 1)^n$. Коэффициент при $x^{n + 1 - k}$ ($1 \leqslant k \leqslant n$) в первом слагаемом — $C_n^k$, во втором — $C_n^{k - 1}$ (при $k = 1$ это коэффициент $1$ при $x^n$); в сумме — $C_{n + 1}^k$ по упражнению 3 (для $k = 1$: $C_n^1 + 1 = n + 1 = C_{n + 1}^1$). Старший коэффициент $1$, свободный член $C_n^n = 1 = C_{n + 1}^{n + 1}$. $\square$

Комбинаторно. В произведении $n$ скобок $(x + 1)$ член $x^{n - k}$ возникает, когда из $k$ скобок взята единица; способов выбрать эти $k$ скобок — $C_n^k$.

Условие $n > 1$ не обязательно: при $n = 1$ формула $(x + 1)^1 = x + C_1^1$ тоже верна.

5. Докажите, что $$1 + C_n^1 + C_n^2 + \ldots + C_n^n = 2^n.$$

Решение 1. Подставим $x = 1$ в упражнение 4: $2^n = 1 + C_n^1 + \ldots + C_n^n$ (для $n = 1$: $1 + 1 = 2$).

Решение 2 (подсчёт). Слева — число всех подмножеств $n$-элементного множества, разбитых по числу элементов: $1$ пустое, $C_n^1$ одноэлементных, …, $C_n^n = 1$ всё множество. Справа — то же число (упражнение 2 § 1: у множества из $n$ элементов $2^n$ подмножеств). $\square$

Проверка. $n = 4$: $1 + 4 + 6 + 4 + 1 = 16$. В ML: $2^n$ подмножеств признаков — поэтому полный перебор признаков невозможен уже при $n = 40$.

6. Докажите, что $\displaystyle\sum_{k=0}^{n} (C_n^k)^2 = C_{2n}^n$.

Тождество Вандермонда (Vandermonde’s identity) в частном случае. Слагаемое с $k = 0$ требует соглашения $C_n^0 = 1$ (одно пустое подмножество) — в упражнении 2 оно не охвачено ($k \geqslant 1$).

Решение. Пусть $M = A \cup B$, $A \cap B = \varnothing$, $|A| = |B| = n$. Число $n$-элементных подмножеств $M$ равно $C_{2n}^n$. Разобьём их по числу $k$ элементов, взятых из $A$: тогда из $B$ взято $n - k$, и таких подмножеств $C_n^k \cdot C_n^{n - k}$. Так как $C_n^{n - k} = C_n^k$ (выбрать $n - k$ элементов — то же, что выбрать $k$ невыбранных), получаем $C_{2n}^n = \sum_{k = 0}^{n} (C_n^k)^2$. $\square$

Проверка. $n = 2$: $1 + 4 + 1 = 6 = C_4^2$; $n = 3$: $1 + 9 + 9 + 1 = 20 = C_6^3$ (проверено и для $n \leqslant 11$).

7. Докажите, что для любых натуральных чисел $a$, $b$, $c$ и $d$ сумма $a + b + c + d$ не зависит от порядка слагаемых.

Под $a + b + c + d$ понимается $((a + b) + c) + d$; по ассоциативности (теорема 2.1) любая расстановка скобок даёт то же число. Порядков слагаемых $4! = 24$.

Лемма. Перестановка двух соседних слагаемых не меняет сумму. Для первых двух: $(a + b) + \ldots = (b + a) + \ldots$ — коммутативность. Для двух соседних в середине или конце: $(x + y) + z = x + (y + z) = x + (z + y) = (x + z) + y$ — ассоциативность, коммутативность, ассоциативность; здесь $x$ — сумма всех предыдущих.

Вывод. Любой порядок слагаемых получается из $a, b, c, d$ последовательностью перестановок соседних (как в сортировке пузырьком: не более $6$ обменов). На каждом шаге сумма не меняется, значит, все $24$ суммы равны. $\square$

Пример. $d + c + b + a$: $abcd \to bacd \to bcad \to bcda \to cbda \to cdba \to dcba$ — шесть обменов соседних. Тот же аргумент для $n$ слагаемых — индукцией по $n$; в программировании это гарантирует, что sum целых не зависит от порядка элементов.

Частые ошибки

В доказательствах параграфа нельзя «просто знать», что $0 + a = a$ или $1 \cdot a = a$: аксиомы дают только $a + 0 = a$ и $a \cdot 0 = 0$. Левые варианты — отдельные результаты (теорема 2.3, лемма 2.11). Порядок теорем важен: коммутативность сложения опирается на лемму 2.2, коммутативность умножения — на правую дистрибутивность 2.10.

Аксиомы раскрывают второй аргумент: $m + (n + 1)$, $m(n + 1)$. Индукция по первому аргументу в $a + (b + c) = (a + b) + c$ упирается в $(a + 1) + \ldots$, о котором аксиомы молчат. Выбирайте переменную, стоящую вторым аргументом.

Индуктивное предположение — $A(n)$ для одного $n$, а не $\forall c\, A(c)$. В шаге надо вывести $A(n + 1)$, применяя аксиомы, а не подставить его.

Закон сокращения для умножения требует $c \ne 0$: из $2 \cdot 0 = 5 \cdot 0$ не следует $2 = 5$. Для сложения ограничений нет — сокращать можно на любое $c$.

$a - b$ в $\mathbf{N}$ определено только при ($\alpha$) или ($\gamma$) теоремы 2.9, т. е. когда $b$ «не больше» $a$. Запись $3 - 5$ в $\mathbf{N}$ бессмысленна, а беззнаковые типы в программах молча дают переполнение.

В этом параграфе несколько опечаток: аксиомы сложения на с. 122 пронумерованы IV и V (по § 1 — III и IV), в теореме 2.15 «$a \ne b$» вместо «$a \ne 0$», в теореме 2.16 ссылка на «теорему 2.8» вместо 2.9. Каждую ссылку сверяйте с формулой, на которую она указывает.

Итоги

  • Аксиомы (по § 1): III $m + 0 = m$, IV $m + (n + 1) = (m + n) + 1$, V $m \cdot 0 = 0$, VI $m(n + 1) = mn + m$ — рекурсия по второму аргументу; вместе с I, II (о «$+1$») и VII (индукция) они однозначно задают сложение и умножение.
  • Сложение: ассоциативно (2.1), коммутативно (2.3, через лемму 2.2 о переносе единицы), $0$ — нейтральный; $\langle \mathbf{N}, +, 0\rangle$ — аддитивный моноид. Закон сокращения $a + c = b + c \Rightarrow a = b$ (2.4).
  • Нуль и предшественник: $a + b \ne a$ при $b \ne 0$ (2.5); каждое $a \ne 0$ есть $b + 1$ (2.6); $a + b = 0$ только при $a = b = 0$ (2.7, 2.8).
  • Трихотомия (2.9): ровно одно из $a = b$, $a + k = b$, $a = b + m$ ($k, m \ne 0$). Разность $a - b$ — единственное $k$ с $b + k = a$; существует только при $a = b$ или $a = b + m$.
  • Умножение: $m \cdot 1 = m$ и $1 \cdot m = m$ (2.11), дистрибутивно справа (2.10) и слева (2.13), коммутативно (2.12), ассоциативно (2.14); $\langle \mathbf{N}, \cdot, 1\rangle$ — мультипликативный моноид. Нет делителей нуля (2.15, в книге опечатка), сокращение на $c \ne 0$ (2.16).
  • Метод один: закрепить лишние переменные, вести индукцию по аргументу, который раскрывают аксиомы, и обобщить в конце.
