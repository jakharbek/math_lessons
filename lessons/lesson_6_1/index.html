Зачем это нужно

Обучить модель — значит найти параметры, при которых функция потерь $L$ минимальна. Параметров — тысячи или миллиарды, формулы для минимума нет. Остаётся идти к нему шагами.

В мы видели, что в точке гладкого минимума производная равна нулю. Для функции одной переменной уравнение $f'(x) = 0$ иногда решается на бумаге. Но у нейросети $L$ зависит от миллионов чисел сразу, и уравнений столько же — решить их явно невозможно. Градиентный спуск обходит проблему: он не ищет минимум формулой, а подходит к нему шаг за шагом, каждый раз спрашивая у производной, куда идти.

Этот алгоритм обучает линейную и логистическую регрессию, нейросети и — в слегка замаскированном виде — градиентный бустинг.

Спуск с горы в тумане

Представьте, что вы стоите на склоне горы в густом тумане и хотите спуститься в долину. Долины не видно — видно только землю под ногами. Разумная стратегия: нащупать, куда склон идёт вниз круче всего, сделать шаг туда и повторить.

Высота — функция потерь, ваше положение — параметры модели, крутизна склона под ногами — производная (на плоскости — градиент), длина шага — темп обучения. Весь алгоритм — «шагни вниз по склону, повтори».

В этой картинке уже видны три вопроса урока: как математически «нащупать склон», какой длины делать шаг и всегда ли так доберёшься до самой низкой точки.

Шаг в одномерном случае

Начнём с функции одной переменной $f(x)$. Производная $f'(x)$ — наклон касательной: если $f'(x) > 0$, функция растёт вправо, значит, спускаться надо влево; если $f'(x) < 0$ — наоборот. В обоих случаях идти нужно против знака производной. Так и устроен шаг:

Выберем начальную точку $x_0$ и число $\eta > 0$ — темп обучения (learning rate). Шаг градиентного спуска:

$$x_{t+1} = x_t - \eta\, f'(x_t), \qquad t = 0, 1, 2, \ldots$$

Почему шаг действительно ведёт вниз? Ответ даёт линейное приближение из урока о производной: $f(x + h) \approx f(x) + f'(x)\,h$.

Если $f$ дифференцируема в точке $x$ и $f'(x) \ne 0$, то при всех достаточно малых $\eta > 0$ выполнено $f\big(x - \eta f'(x)\big) < f(x)$.

Доказательство

Положим $h = -\eta f'(x)$. По определению производной разностное отношение $\frac{f(x+h) - f(x)}{h}$ стремится к $f'(x)$ при $h \to 0$, то есть равно $f'(x) + \alpha$, где $\alpha \to 0$. Тогда

$$f(x+h) - f(x) = \big(f'(x) + \alpha\big)\,h = -\eta\, f'(x)^2 - \eta\,\alpha\, f'(x).$$

Первое слагаемое отрицательно и равно $-\eta f'(x)^2$. Второе по модулю равно $\eta\,|\alpha|\,|f'(x)|$, и при малом $\eta$ (а значит, малом $h$) множитель $|\alpha|$ станет меньше $|f'(x)|$. Тогда второе слагаемое меньше первого по модулю, и сумма отрицательна.

Темп обучения

Для $f(x) = x^2$ шаг можно записать в закрытом виде: $x_{t+1} = x_t - 2\eta\,x_t = (1 - 2\eta)\,x_t$, и значит,

$$x_t = (1 - 2\eta)^t\, x_0.$$

Вся судьба спуска определяется одним числом — множителем $q = 1 - 2\eta$. Если $|q| < 1$, степени $q^t$ стремятся к нулю, и спуск сходится; если $|q| > 1$ — разлетается.

В градиентном бустинге та же роль у темпа обучения $\nu$ (shrinkage): каждое новое дерево добавляется с множителем $\nu$, и маленькие $\nu$ требуют больше деревьев. Подробно — в курсе «Градиентный бустинг по косточкам», урок «Где спрятан градиентный спуск».

Частные производные и градиент

У модели не один параметр, а много. Пусть пока их два: функция $f(x, y)$ — это рельеф над плоскостью, высота в каждой точке $(x, y)$. Как измерить наклон, если идти можно в любую сторону?

Начнём с двух простейших направлений — вдоль осей. Зафиксируем $y$ и будем менять только $x$: получится обычная функция одной переменной, и у неё есть обычная производная.

Частной производной функции $f(x, y)$ по $x$ называется производная по $x$ при фиксированном $y$:

$$\frac{\partial f}{\partial x}(x, y) = \lim_{h \to 0} \frac{f(x + h,\, y) - f(x, y)}{h}.$$

Частная производная по $y$ определяется так же, с фиксированным $x$.

Градиентом функции $f(x, y)$ называется вектор из её частных производных:

$$\nabla f(x, y) = \left(\frac{\partial f}{\partial x},\; \frac{\partial f}{\partial y}\right).$$

Пусть $f(x, y) = x^2 + 5y^2$. При фиксированном $y$ слагаемое $5y^2$ — константа, её производная ноль, поэтому $\frac{\partial f}{\partial x} = 2x$. Аналогично $\frac{\partial f}{\partial y} = 10y$. Итак, $\nabla f(x, y) = (2x,\; 10y)$; например, в точке $(1, 2)$ градиент равен $(2, 20)$.

Значок $\nabla$ читается «набла». Для функции $n$ переменных градиент — вектор из $n$ частных производных; всё, что дальше, переносится на него без изменений.

Почему именно градиент

Градиент собран из наклонов вдоль осей. Но почему он указывает направление самого крутого подъёма, а не просто какое-то направление? Пусть мы идём из точки $(x, y)$ в направлении единичного вектора $\mathbf{u} = (u_1, u_2)$, $u_1^2 + u_2^2 = 1$. Наклон в этом направлении — производная по направлению (directional derivative) — по линейному приближению равен

$$D_{\mathbf{u}} f = \frac{\partial f}{\partial x}\,u_1 + \frac{\partial f}{\partial y}\,u_2 = \nabla f \cdot \mathbf{u}.$$

Справа стоит скалярное произведение (dot product) — сумма попарных произведений координат. У него есть геометрический смысл, который мы подробно разберём в : $\mathbf{a} \cdot \mathbf{b} = |\mathbf{a}|\,|\mathbf{b}|\cos\varphi$, где $\varphi$ — угол между векторами.

Если $\nabla f(x, y) \ne \mathbf{0}$, то среди всех единичных направлений $\mathbf{u}$ производная по направлению $D_{\mathbf{u}} f$ наибольшая для $\mathbf{u} = \nabla f / |\nabla f|$ и наименьшая для $\mathbf{u} = -\nabla f / |\nabla f|$. Её значения при этом равны $\pm|\nabla f|$.

Доказательство

По формуле и геометрическому смыслу скалярного произведения $D_{\mathbf{u}} f = |\nabla f|\cdot 1 \cdot \cos\varphi$, где $\varphi$ — угол между $\nabla f$ и $\mathbf{u}$. Косинус максимален ($= 1$) при $\varphi = 0$, то есть когда $\mathbf{u}$ сонаправлен с градиентом, и минимален ($= -1$) при $\varphi = 180^\circ$.

Отсюда ещё одно следствие. Линия уровня — кривая, на которой $f$ постоянна, как горизонталь на топографической карте. Двигаясь вдоль неё, высота не меняется, значит, $D_{\mathbf{u}} f = 0$ и $\cos\varphi = 0$: градиент перпендикулярен линиям уровня. На карте это видно сразу — стрелка градиента всегда пересекает горизонтали под прямым углом.

Спуск на плоскости

Теперь шаг градиентного спуска для многих переменных пишется так же, как для одной, только вместо производной — градиент:

$$\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta\, \nabla f(\boldsymbol{\theta}_t).$$

Здесь $\boldsymbol{\theta} = (x, y)$ — точка на плоскости, а у настоящей модели — вектор всех параметров. Это ровно та формула, что на главной странице курса.

Линии уровня — как горизонтали на карте. Щёлкните по карте, чтобы выбрать старт. Чёрная стрелка — направление градиента (наискорейший подъём), синяя — сделанный шаг $-\eta\nabla f$. Сравните «чашу» и «овраг» при одном и том же $\eta$.

Овраг: почему один темп на всех — компромисс

Для $f = x^2 + 5y^2$ шаг распадается на два независимых: $x_{t+1} = (1 - 2\eta)\,x_t$ и $y_{t+1} = (1 - 10\eta)\,y_t$. Спуск сходится, только если оба множителя по модулю меньше единицы, то есть при $\eta < 0{,}2$ — границу задаёт самое крутое направление. Но вдоль пологого направления $x$ при таком $\eta$ шаги маленькие.

Отсюда знакомая картина: при $\eta = 0{,}18$ по $y$ множитель $1 - 1{,}8 = -0{,}8$ — спуск мечется от стенки к стенке оврага, а по $x$ (множитель $0{,}64$) медленно ползёт вдоль дна. При $\eta = 0{,}21$ множитель по $y$ равен $-1{,}1$, и спуск вылетает из оврага. Этот эффект — главная причина, по которой придуманы методы с инерцией (momentum) и адаптивные методы вроде Adam.

Локальные минимумы

Градиентный спуск видит только склон под ногами. Если у функции несколько ям, он скатится в ту, на чьём склоне начал, — и не узнает, что где-то есть яма глубже.

У функции $f(x) = x^4 - 3x^2 + x$ два минимума: около $x \approx -1{,}30$ (там $f \approx -3{,}51$) и около $x \approx 1{,}13$ (там $f \approx -1{,}07$). Спуск из $x_0 = -0{,}5$ скатывается в глубокую левую яму, а из $x_0 = 0{,}4$ — в мелкую правую: между ними горб в точке $x \approx 0{,}17$. Проверьте на первом рисунке, выбрав функцию «две ямы».

Точку, где функция меньше, чем во всех близких точках, называют локальным минимумом; самую низкую точку вообще — глобальным. Есть функции, у которых любой локальный минимум глобальный, — выпуклые; им посвящён . Функции потерь линейной и логистической регрессии выпуклы, нейросетей — нет, и тем не менее спуск с хорошей инициализацией находит у них хорошие решения.

Частые ошибки

Градиент указывает, где функция растёт. Для минимизации нужен знак минус: $\boldsymbol\theta - \eta\nabla f$. Плюс даёт градиентный подъём — он тоже бывает нужен, например при максимизации правдоподобия.

До порога увеличение $\eta$ ускоряет спуск, после — приводит к колебаниям и расхождению. Если потери на обучении растут или «скачут», первым делом уменьшают темп обучения.

Спуск подходит к минимуму бесконечно долго: $|q|^t$ никогда не станет нулём. На практике останавливаются, когда $|\nabla f|$ или изменение потерь становится меньше порога, или по числу шагов.

Задачи

Для $f(x) = (x - 2)^2$, $\eta = 0{,}25$, $x_0 = 0$ сделайте два шага градиентного спуска. Найдите формулу для $x_t$.

Решение

$f'(x) = 2(x - 2)$. Шаг: $x_{t+1} = x_t - 0{,}5(x_t - 2)$. $x_1 = 0 - 0{,}5\cdot(-2) = 1$, $x_2 = 1 - 0{,}5\cdot(-1) = 1{,}5$.

Расстояние до минимума $x_t - 2$ каждый раз умножается на $0{,}5$: $x_t = 2 - 2\cdot 0{,}5^t$.

Найдите градиент функции $f(x, y) = x^2 y + y^3$ в точке $(1, 2)$. В каком направлении из этой точки функция быстрее всего убывает?

Решение

$\frac{\partial f}{\partial x} = 2xy$, $\frac{\partial f}{\partial y} = x^2 + 3y^2$. В точке $(1, 2)$: $\nabla f = (4,\; 13)$.

Быстрее всего функция убывает в направлении $-\nabla f = (-4, -13)$, нормированном: $(-4, -13)/\sqrt{185}$.

Пусть $f(x) = \frac{a}{2}x^2$, $a > 0$. При каких $\eta$ градиентный спуск сходится к минимуму из любой начальной точки? При каком $\eta$ — за один шаг?

Решение

$f'(x) = ax$, шаг $x_{t+1} = (1 - \eta a)\,x_t$. Сходимость при $|1 - \eta a| < 1$, то есть $0 < \eta < 2/a$. За один шаг — при $1 - \eta a = 0$, $\eta = 1/a$.

Чем круче парабола (больше $a$ — вторая производная), тем меньше допустимый темп. Для $x^2$ ($a = 2$) получаем порог $1$ и идеальный темп $0{,}5$ — как в таблице выше.

Итоги

  • Шаг $x_{t+1} = x_t - \eta f'(x_t)$ идёт против наклона; при малом $\eta$ он уменьшает функцию — это следует из линейного приближения.
  • Темп обучения решает всё: мало — ползёт, в меру — сходится, слишком много — колеблется и разлетается. Для $\frac{a}{2}x^2$ порог равен $2/a$.
  • Частная производная — обычная производная по одной переменной при фиксированных остальных; градиент — вектор из них.
  • Градиент — направление наискорейшего роста, перпендикулярное линиям уровня; спуск идёт против него: $\boldsymbol\theta_{t+1} = \boldsymbol\theta_t - \eta\nabla f(\boldsymbol\theta_t)$.
  • В оврагах один темп на все направления — компромисс; при нескольких ямах результат зависит от старта.
