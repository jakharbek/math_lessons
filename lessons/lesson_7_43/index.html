Зачем это нужно

Линейный оператор можно «отменить», если по результату $\varphi(\boldsymbol{x})$ всегда однозначно восстанавливается исходный вектор $\boldsymbol{x}$. Такие операторы называются обратимыми (invertible), а отменяющий оператор — обратным (inverse), $\varphi^{-1}$. Главный результат параграфа — теорема 4.1: для оператора конечномерного пространства шесть разных на вид свойств — обратимость, взаимная однозначность, нулевое ядро, нулевой дефект, полный ранг, обратимость матрицы — на самом деле одно и то же. Затем книга собирает все обратимые операторы в группу $\mathscr{A}\mathit{ut}\,\mathscr{V}$ и доказывает, что она изоморфна полной линейной группе (general linear group) $GL(n, \mathscr{F})$ обратимых матриц.

Опираемся на предыдущие параграфы главы восьмой: линейный оператор, ядро и образ, ранг и дефект, теорема 1.4 о сумме ранга и дефекта — ; матрица оператора, теоремы 2.1, 2.3, 2.6 — ; произведение операторов, алгебра $\mathit{End}\,\mathscr{V}$ и теорема 3.3 об её изоморфизме с полной матричной алгеброй — . Из прошлых глав нужны: обратимые функции и ассоциативность композиции — ; изоморфизм и автоморфизм алгебр — ; группы и теорема 3.1 о гомоморфизме групп — ; обратимые матрицы и группа $GL(n, \mathscr{F})$ — ; ранг матрицы — ; базис и размерность — ; изоморфизм векторных пространств — .

Где это встречается в программировании и машинном обучении:

  • решение систем и обращение: numpy.linalg.solve(A, b) работает только для обратимой $A$; проверка «обратима ли» — это проверка любого из условий теоремы 4.1 (полный ранг matrix_rank(A) == n, нулевое ядро, $\det A \ne 0$);
  • обратимые преобразования данных: смена базиса, отбеливание (whitening) $\boldsymbol{x} \mapsto \Sigma^{-1/2}\boldsymbol{x}$, перевод цветов RGB ↔ YCbCr — их можно отменить без потери информации; проекция PCA на меньшее число компонент — нельзя: у неё ненулевое ядро;
  • нормализующие потоки (normalizing flows) в генеративных моделях строят из обратимых слоёв, в том числе обратимых линейных $\boldsymbol{x} \mapsto W\boldsymbol{x}$ с $W \in GL(n, \mathscr{R})$; формула $(\varphi\psi)^{-1} = \psi^{-1}\varphi^{-1}$ (упражнение 1) — правило обращения цепочки слоёв;
  • группа $GL(n)$ — язык компьютерной графики и робототехники: повороты, масштабирования, сдвиги экрана — элементы $GL(2, \mathscr{R})$ и $GL(3, \mathscr{R})$, а «отменить» последовательность преобразований — значит применить обратные в обратном порядке.

Обратимые операторы

§ 4. ОБРАТИМЫЕ ОПЕРАТОРЫ

Обратимые операторы.

Пусть $\varphi$ — линейный оператор векторного пространства $\mathscr{V}$ и $\varepsilon$ — тождественный оператор этого пространства.

Исходные данные определения. Линейный оператор $\varphi$ — линейное отображение $\mathscr{V}$ в себя: $\varphi(\boldsymbol{a} + \boldsymbol{b}) = \varphi(\boldsymbol{a}) + \varphi(\boldsymbol{b})$, $\varphi(\lambda\boldsymbol{a}) = \lambda\varphi(\boldsymbol{a})$ (). Тождественный оператор $\varepsilon$ ничего не меняет: $\varepsilon(\boldsymbol{x}) = \boldsymbol{x}$ для всех $\boldsymbol{x} \in V$; он линеен и играет роль единицы при умножении операторов: $\varphi\varepsilon = \varepsilon\varphi = \varphi$.

Размерность $\mathscr{V}$ здесь не ограничена: определение и первые утверждения параграфа годятся и для бесконечномерных пространств. Конечномерность понадобится только в теореме 4.1.

Роль у предложения — «определение»: следующее предложение пользуется введёнными здесь $\varphi$ и $\varepsilon$ и без этой посылки не читается.

Оператор $\varphi$ называется обратимым, если существует такой линейный оператор $\psi$ пространства $\mathscr{V}$, что $$\text{(1)}\quad \varphi\psi = \varepsilon,\ \ \psi\varphi = \varepsilon,$$

По косточкам.

  • «существует такой линейный оператор $\psi$» — обратимость есть утверждение о существовании второго оператора; сам $\varphi$ по виду не «помечен» как обратимый;
  • $\varphi\psi = \varepsilon$: $\varphi(\psi(\boldsymbol{x})) = \boldsymbol{x}$ для всех $\boldsymbol{x}$ — сначала $\psi$, потом $\varphi$, и вектор возвращается на место; значит, $\psi$ — правый обратный к $\varphi$;
  • $\psi\varphi = \varepsilon$: $\psi(\varphi(\boldsymbol{x})) = \boldsymbol{x}$ — $\psi$ отменяет действие $\varphi$; $\psi$ — левый обратный;
  • требуются оба равенства (1). В бесконечномерном пространстве одного недостаточно — см. контрпример ниже; в конечномерном одно влечёт другое (упражнение 4, № 52);
  • $\psi$ обязан быть линейным оператором пространства $\mathscr{V}$. На деле это не ограничение: если отображение $\psi$ удовлетворяет (1), то оно линейно автоматически, — $\psi(\boldsymbol{a} + \boldsymbol{b}) = \psi(\varphi\psi(\boldsymbol{a}) + \varphi\psi(\boldsymbol{b})) = \psi\varphi(\psi(\boldsymbol{a}) + \psi(\boldsymbol{b})) = \psi(\boldsymbol{a}) + \psi(\boldsymbol{b})$, и так же для $\lambda\boldsymbol{a}$.

Это частный случай обратимой функции из : функция $f$ обратима, если у неё есть двусторонняя обратная. Новое только одно — внутри мира линейных операторов.

(а) На числах. На $\mathscr{R}^2$ оператор $\varphi(x_1, x_2) = (2x_1 + x_2,\ x_1 + x_2)$ обратим: $\psi(y_1, y_2) = (y_1 - y_2,\ -y_1 + 2y_2)$. Проверка: $\varphi(\psi(\boldsymbol{y})) = (2y_1 - 2y_2 - y_1 + 2y_2,\ y_1 - y_2 - y_1 + 2y_2) = (y_1, y_2)$ и $\psi(\varphi(\boldsymbol{x})) = (2x_1 + x_2 - x_1 - x_2,\ -2x_1 - x_2 + 2x_1 + 2x_2) = (x_1, x_2)$. Поворот плоскости на $90^\circ$ обратим: обратный — поворот на $-90^\circ$.

(б) Из жизни. Перевод цен из рублей в доллары по курсу — линейный оператор, обратный ему — перевод обратно по тому же курсу. Шифр «сдвиг каждой буквы на 3» обратим (сдвиг на $-3$), хотя он и не линейный.

(в) В программировании. Преобразование цветов RGB → YCbCr в JPEG — умножение на обратимую $3 \times 3$-матрицу; декодер умножает на обратную. В NumPy: A_inv = np.linalg.inv(A), и A @ A_inv, A_inv @ A — единичные (с точностью до округления).

Проекция $\varphi(x_1, x_2) = (x_1, 0)$ необратима: $\varphi(0, 1) = \varphi(0, 2) = \mathbf{0}$, и никакой $\psi$ не может вернуть и $(0, 1)$, и $(0, 2)$. Одного равенства мало: в пространстве всех многочленов над $\mathscr{R}$ пусть $D(p) = p'$ (производная) и $J(p) = \int_0^x p(t)\,dt$. Тогда $DJ = \varepsilon$ (производная интеграла — исходный многочлен), но $JD \ne \varepsilon$: $JD(1) = J(0) = 0 \ne 1$. Ни $D$, ни $J$ не обратимы: $D$ не инъективен ($D(1) = D(2)$), $J$ не «на» (константа $1$ не интеграл с нулевым свободным членом).

Предложение кончается на формуле (1) запятой, а следующая страница начинается новым предложением с прописной буквы и с красной строки. По смыслу после (1) должна стоять точка; в цитате — как напечатано.

Оператор $\psi$, удовлетворяющий условиям (1), существует только один.

Утверждение о единственности: у обратимого оператора ровно один «двусторонний отменитель». Без этого нельзя было бы говорить «обратный оператор» и вводить обозначение $\varphi^{-1}$ (№ 5). Доказательство — следующее предложение; оно не использует ни линейности, ни конечномерности, только ассоциативность композиции. Это та же выкладка, что для единственности обратного элемента в группе (свойство 3.2, ) и обратной матрицы ().

Действительно, если оператор $\psi_1$ удовлетворяет условиям $\varphi\psi_1 = \varepsilon$, $\psi_1\varphi = \varepsilon$, то $$\psi_1 = \psi_1\varepsilon = \psi_1(\varphi\psi) = (\psi_1\varphi)\psi = \varepsilon\psi = \psi,\ \text{т. е.}\ \psi_1 = \psi.$$

Разбор цепочки по звеньям:

  1. $\psi_1 = \psi_1\varepsilon$ — $\varepsilon$ нейтрален при умножении: $\psi_1(\varepsilon(\boldsymbol{x})) = \psi_1(\boldsymbol{x})$;
  2. $\psi_1\varepsilon = \psi_1(\varphi\psi)$ — подставили $\varepsilon = \varphi\psi$ из (1) для $\psi$;
  3. $\psi_1(\varphi\psi) = (\psi_1\varphi)\psi$ — ассоциативность композиции (теорема 3.5 главы 2, );
  4. $(\psi_1\varphi)\psi = \varepsilon\psi$ — по условию на $\psi_1$: $\psi_1\varphi = \varepsilon$;
  5. $\varepsilon\psi = \psi$ — снова нейтральность $\varepsilon$.

Заметьте: использованы лишь половины условий — у $\psi$ правая ($\varphi\psi = \varepsilon$), у $\psi_1$ левая ($\psi_1\varphi = \varepsilon$). Значит, верно больше: любой левый обратный совпадает с любым правым обратным, если оба существуют. Этим фактом мы воспользуемся в упражнении 2.

(а) На числах. Для $\varphi(x_1, x_2) = (2x_1 + x_2, x_1 + x_2)$ условие $\varphi\psi = \varepsilon$ на матрицах — $\begin{bmatrix}2 & 1\\ 1 & 1\end{bmatrix}X = E$; это система с единственным решением $X = \begin{bmatrix}1 & -1\\ -1 & 2\end{bmatrix}$ — другого обратного нет.

(б) Из жизни. Если и Аня, и Борис умеют «отменить» шифр Цезаря со сдвигом 3, их способы дают на любом тексте один и тот же результат — сдвиг на $-3$.

(в) В программировании. Поэтому функция np.linalg.inv вправе возвращать одну матрицу: какой бы алгоритм её ни считал (Гаусс, LU, QR), ответ один и тот же — с точностью до ошибок округления.

Линейный оператор $\psi$, удовлетворяющий условиям (1), называется обратным к оператору $\varphi$ и обозначается $\varphi^{-1}$.

По косточкам. «Обратный к оператору $\varphi$» — тот самый единственный $\psi$ из (1); корректность названия обеспечена предыдущим предложением. Обозначение $\varphi^{-1}$ — как у обратной функции и обратной матрицы. Равенства (1) теперь читаются так: $\varphi\varphi^{-1} = \varphi^{-1}\varphi = \varepsilon$. Из симметрии условий (1) следует: $\varphi^{-1}$ тоже обратим и $(\varphi^{-1})^{-1} = \varphi$.

(а) На числах. Поворот $\rho$ плоскости на $90^\circ$: $\rho(x_1, x_2) = (-x_2, x_1)$, $\rho^{-1}(x_1, x_2) = (x_2, -x_1)$ — поворот на $-90^\circ$; так как $\rho^4 = \varepsilon$, ещё и $\rho^{-1} = \rho^3$. Сдвиг $\sigma(x_1, x_2) = (x_1 + x_2, x_2)$ — $\sigma^{-1}(x_1, x_2) = (x_1 - x_2, x_2)$. Растяжение $x \mapsto 5x$ на прямой $\mathscr{R}^1$ — обратное $x \mapsto \frac15 x$.

(б) Из жизни. Перевод температуры из шкалы «градусы в десятых долях» в обычную ($x \mapsto x/10$) и обратно ($x \mapsto 10x$).

(в) В машинном обучении. Стандартизация признаков $x \mapsto x/\sigma$ — линейный оператор; StandardScaler.inverse_transform применяет обратный $x \mapsto \sigma x$ (сдвиг на среднее уже не линейный, а аффинный).

Не путайте $\varphi^{-1}$ с «полным прообразом» из главы 2: запись $\varphi^{-1}(\boldsymbol{b})$ для множества $\{\boldsymbol{x} \mid \varphi(\boldsymbol{x}) = \boldsymbol{b}\}$ имеет смысл для любого $\varphi$ (в § 1 так записано $\mathrm{Ker}\,\varphi = \varphi^{-1}(\mathbf{0})$), а оператор $\varphi^{-1}$ существует лишь у обратимого. Для проекции $\varphi(x_1, x_2) = (x_1, 0)$ множество $\varphi^{-1}(\mathbf{0}) = \{(0, t)\}$ — целая прямая, а оператора $\varphi^{-1}$ нет. И $\varphi^{-1}$ — не «$1/\varphi$»: делить на оператор нельзя.

Обратимый и вырожденный оператор плоскости. Ползунки задают матрицу $M(\varphi)$ относительно базиса $\boldsymbol{e}_1$, $\boldsymbol{e}_2$; по Куликову её первый столбец — координаты $\varphi(\boldsymbol{e}_1)$ (синяя стрелка), второй — координаты $\varphi(\boldsymbol{e}_2)$ (оранжевая стрелка). Пунктиром — единичный квадрат, закрашен его образ, тонкие линии — образ координатной сетки. Табло показывает определитель, ранг и дефект; если оператор обратим, там же — матрица $M(\varphi^{-1})$ (по строкам), а флажок «применить $\varphi^{-1}$» возвращает образ на место. Кнопки «поворот», «сдвиг», «растяжение», «вырожденный» задают готовые матрицы; у вырожденного оператора плоскость сплющивается в прямую, а ядро $\mathrm{Ker}\,\varphi$ показано бирюзовой прямой — сравните с условиями (c)–(f) теоремы 4.1.

ТЕОРЕМА 4.1. Пусть $\varphi$ — линейный оператор конечномерного ненулевого векторного пространства $\mathscr{V}$.

По косточкам. Посылка теоремы. «Конечномерного» — у $\mathscr{V}$ есть конечный базис $\boldsymbol{e}_1, \ldots, \boldsymbol{e}_n$, иначе не определены ранг, дефект и матрица оператора (условия (d)–(f)) и не работает теорема 1.4. «Ненулевого» — $n \geqslant 1$: в нулевом пространстве нет базиса и матрицы; впрочем, там единственный оператор $\varphi = \varepsilon$ обратим тривиально.

(а) На числах. $\mathscr{R}^2$, $\mathscr{R}^3$, $\mathbf{Z}_2^4$, пространство многочленов степени $\leqslant 3$ (размерность $4$).

(б) Из жизни. «Корзина» из $n$ товаров: вектор количеств — элемент $n$-мерного пространства.

(в) В машинном обучении. Пространство признаков $\mathbf{R}^d$ — конечномерно, поэтому для квадратных весовых матриц слоёв верны все равносильности теоремы.

Пространство всех многочленов бесконечномерно, и для него теорема неверна: оператор $J(p) = \int_0^x p$ инъективен ($\mathrm{Ker}\,J = \{\mathbf{0}\}$, условие (c)), но не обратим — его образ не содержит констант $\ne 0$. Конечномерность — существенное условие.

Тогда следующие условия равносильны:
(a) оператор $\varphi$ обратим;
(b) $\varphi$ есть инъективное отображение $\mathscr{V}$ на $\mathscr{V}$;
(c) $\mathrm{Ker}\,\varphi = \{\mathbf{0}\}$;
(d) дефект $\varphi = 0$;
(e) ранг $\varphi = \dim\mathscr{V}$;
(f) матрица оператора $\varphi$ относительно любого базиса пространства $\mathscr{V}$ обратима.

По косточкам. «Равносильны» — из любого условия следует любое другое. Доказательство идёт по кругу (a) ⇒ (b) ⇒ (c) ⇒ (d) ⇒ (e) ⇒ (f) ⇒ (a): шести импликаций хватает вместо тридцати.

  • (a) — алгебраическое: есть двусторонний обратный;
  • (b) — теоретико-множественное: $\varphi$ — биекция $V$ на $V$ («инъективное» — разные векторы переходят в разные, «на» — каждый вектор чей-то образ);
  • (c) — только нулевой вектор переходит в нуль; (d) — то же на языке размерностей: $\dim\mathscr{K}\mathit{er}\,\varphi = 0$;
  • (e) — образ — всё пространство (по размерности); (f) — матричное: $M(\varphi)$ обратима, т. е. $\det M(\varphi) \ne 0$ ().

Самое неожиданное: (c) — проверка одного уравнения $\varphi(\boldsymbol{x}) = \mathbf{0}$ — даёт сразу и инъективность, и сюръективность. Это чисто конечномерный эффект: по теореме 1.4 «потерять» размерность в ядре и не потерять её в образе невозможно.

(а) На числах. $\varphi(x_1, x_2) = (2x_1 + x_2, x_1 + x_2)$: $M(\varphi) = \begin{bmatrix}2 & 1\\ 1 & 1\end{bmatrix}$, $\det = 1 \ne 0$ — (f) выполнено, значит, $\mathrm{Ker}\,\varphi = \{\mathbf{0}\}$, ранг $= 2$ и $\varphi$ обратим. Доказательство. Пусть $\varphi$ — обратимый оператор и $\psi$ — оператор, обратный $\varphi$.

Начало круга: шаг (a) ⇒ (b). Предполагаем (a) и даём обратному оператору имя $\psi$ (это $\varphi^{-1}$). Дальше нужно проверить две половины условия (b): инъективность (№ 9, № 10) и то, что $\varphi$ — отображение «на» (№ 11, № 12). Конечномерность на этом шаге не нужна.

Докажем, что $\varphi$ инъективно, т. е. для любых $\boldsymbol{a}, \boldsymbol{b} \in V$, из $\varphi(\boldsymbol{a}) = \varphi(\boldsymbol{b})$ следует $\boldsymbol{a} = \boldsymbol{b}$.

Напоминание определения инъективности (): равные образы бывают только у равных векторов. $V$ — основное множество пространства $\mathscr{V}$; книга пишет здесь $V$, а не $\mathscr{V}$, потому что речь о векторах как элементах множества.

Действительно, если $\varphi(\boldsymbol{a}) = \varphi(\boldsymbol{b})$, то $$\psi(\varphi(\boldsymbol{a})) = \psi(\varphi(\boldsymbol{b}),\ (\psi\varphi)(\boldsymbol{a}) = (\psi\varphi)(\boldsymbol{b}),\ \varepsilon(\boldsymbol{a}) = \varepsilon(\boldsymbol{b}),\ \boldsymbol{a} = \boldsymbol{b}.$$

Цепочка из четырёх равенств, каждое следует из предыдущего:

  1. применили $\psi$ к обеим частям — равные векторы имеют равные образы (это верно для любой функции);
  2. переписали по определению произведения: $\psi(\varphi(\boldsymbol{x})) = (\psi\varphi)(\boldsymbol{x})$;
  3. $\psi\varphi = \varepsilon$ — второе равенство (1);
  4. $\varepsilon(\boldsymbol{x}) = \boldsymbol{x}$.

Для инъективности понадобился только левый обратный ($\psi\varphi = \varepsilon$).

В первом равенстве у правой части не хватает закрывающей скобки: напечатано «$\psi(\varphi(\boldsymbol{b})$», должно быть $\psi(\varphi(\boldsymbol{b}))$. В цитате — как напечатано.

Кроме того, $\varphi$ есть отображение на $V$, т. е. для любого $\boldsymbol{a} \in V$ существует прообраз.

Вторая половина (b): сюръективность. «Прообраз» вектора $\boldsymbol{a}$ — такой $\boldsymbol{x}$, что $\varphi(\boldsymbol{x}) = \boldsymbol{a}$. Кандидат подсказывает обратный оператор: $\boldsymbol{x} = \psi(\boldsymbol{a})$.

Действительно, $$\varphi(\psi(\boldsymbol{a})) = (\varphi\psi)\boldsymbol{a} = \varepsilon\boldsymbol{a} = \boldsymbol{a},$$ т. е. $\psi(\boldsymbol{a})$ есть прообраз элемента $\boldsymbol{a}$ при отображении $\varphi$.

Используется правый обратный: $\varphi\psi = \varepsilon$. Запись $(\varphi\psi)\boldsymbol{a}$ без скобок вокруг $\boldsymbol{a}$ — то же, что $(\varphi\psi)(\boldsymbol{a})$; книга часто так сокращает. Итак, (a) ⇒ (b) доказано: левый обратный дал инъективность, правый — сюръективность.

Проверка на числах. $\varphi(x_1, x_2) = (2x_1 + x_2, x_1 + x_2)$, $\boldsymbol{a} = (3, 2)$: $\psi(\boldsymbol{a}) = (3 - 2, -3 + 4) = (1, 1)$, и действительно $\varphi(1, 1) = (3, 2)$.

Если $\varphi$ есть инъекция, то нулевой вектор $\mathbf{0}$ имеет единственный прообраз при отображении $\varphi$, т. е. $\mathrm{Ker}\,\varphi = \{\mathbf{0}\}$.

Шаг (b) ⇒ (c). Один прообраз у $\mathbf{0}$ заведомо есть: $\varphi(\mathbf{0}) = \mathbf{0}$ для любого линейного оператора ($\varphi(\mathbf{0}) = \varphi(0\cdot\mathbf{0}) = 0\cdot\varphi(\mathbf{0}) = \mathbf{0}$). Инъективность запрещает второй. Ядро — это и есть множество всех прообразов нуля, $\mathrm{Ker}\,\varphi = \varphi^{-1}(\mathbf{0})$ (§ 1), поэтому оно состоит из одного $\mathbf{0}$. Из (b) использована только инъективность.

Если $\mathrm{Ker}\,\varphi = \{\mathbf{0}\}$, то размерность ядра оператора $\varphi$ равна нулю, т. е. дефект $\varphi = 0$.

Шаг (c) ⇒ (d). Подпространство $\{\mathbf{0}\}$ — нулевое, его размерность $0$ (базис пуст, ), а дефект по определению — размерность ядра $\mathscr{K}\mathit{er}\,\varphi$. Шаг верен и в обратную сторону: нулевую размерность имеет только нулевое подпространство.

Если дефект $\varphi = 0$, то по теореме 1.4, ранг $\varphi = \dim\mathscr{V}$.

Шаг (d) ⇒ (e). Теорема 1.4 (): ранг $\varphi$ $+$ дефект $\varphi$ $= \dim\mathscr{V}$; при дефекте $0$ получаем ранг $= \dim\mathscr{V}$. Здесь впервые нужна конечномерность — теорема 1.4 о конечномерном пространстве. Смысл: образ $\mathscr{I}\mathit{m}\,\varphi$ — подпространство полной размерности, значит, совпадает с $\mathscr{V}$; оператор — «на».

Проверка. Для $\chi(x_1, x_2) = (x_1 + 2x_2, 2x_1 + 4x_2)$ дефект $1$, ранг $1$, $1 + 1 = 2 = \dim\mathscr{R}^2$.

Предположим, что ранг $\varphi = \dim\mathscr{V} = n$.

Шаг (e) ⇒ (f). Размерности дано имя $n$; $n \geqslant 1$, так как пространство ненулевое. Нужно доказать обратимость матрицы оператора относительно любого базиса; поэтому базис в следующем предложении произволен.

Пусть $\boldsymbol{e}_1, \ldots, \boldsymbol{e}_n$ — фиксированный базис пространства $\mathscr{V}$.

«Фиксированный» — выбран и дальше не меняется, но выбран произвольно; всё, что будет доказано для него, верно для любого базиса — так и получается «относительно любого базиса» в (f). Матрица $M(\varphi)$ — $n \times n$, её $k$-й столбец — координаты $\varphi(\boldsymbol{e}_k)$.

Многоточие в «$\boldsymbol{e}_1, \ldots, \boldsymbol{e}_n$» повторено на переносе строки («…» в конце строки и в начале следующей); в цитате оно дано один раз.

По теореме 2.6, ранг матрицы $M(\varphi)$ равен рангу оператора $\varphi$ и, значит, равен $n$.

Теорема 2.6 (): ранг оператора конечномерного ненулевого пространства равен рангу его матрицы. Причина: столбцы $M(\varphi)$ — координатные столбцы векторов $\varphi(\boldsymbol{e}_1), \ldots, \varphi(\boldsymbol{e}_n)$, которые порождают образ; а переход к координатам сохраняет линейную зависимость (изоморфизм, ). Получаем: $n \times n$-матрица ранга $n$.

Таким образом, строки матрицы $M(\varphi)$ линейно независимы.

Ранг матрицы — это и строчечный, и столбцовый ранг: они равны (). Строк $n$, и ранг системы строк $n$ — значит, система строк линейно независима (иначе одну строку можно было бы выразить через остальные и ранг был бы меньше $n$). Обратите внимание: у Куликова координаты образов стоят в столбцах $M(\varphi)$, а вывод сделан о строках — переход и обеспечивает равенство строчечного и столбцового рангов.

Следовательно, по теореме 5.1, матрица $M(\varphi)$ обратима.

Нужный факт: квадратная матрица с линейно независимыми строками обратима. В книге это теорема 2.8 главы 6 «(a) матрица $A$ обратима; (b) строки (столбцы) матрицы $A$ линейно независимы; …» (); то же входит в теорему 5.10 главы 6 (). Шаг (e) ⇒ (f) доказан.

Ссылка «по теореме 5.1» неверна: в главе 8 теоремы 5.1 нет (в § 5 есть предложение 5.1 — о собственных векторах), а в § 5 главы 6 номер 5.1 у леммы о разложении определителя. Нужная теорема — 6.2.8 (теорема 2.8 главы 6); подходит и теорема 6.5.10.

Предположим, что матрица $M(\varphi)$ обратима и $B$ — обратная к ней матрица, т. е. $$M(\varphi)B = E\ \text{и}\ BM(\varphi) = E.$$

Последний шаг круга: (f) ⇒ (a). Пример. $M(\varphi) = \begin{bmatrix}2 & 1\\ 1 & 1\end{bmatrix}$, $B = \begin{bmatrix}1 & -1\\ -1 & 2\end{bmatrix}$; оператор $\psi$ с этой матрицей: $\psi(\boldsymbol{e}_1) = \boldsymbol{e}_1 - \boldsymbol{e}_2$, $\psi(\boldsymbol{e}_2) = -\boldsymbol{e}_1 + 2\boldsymbol{e}_2$, т. е. $\psi(y_1, y_2) = (y_1 - y_2, -y_1 + 2y_2)$ — тот самый обратный из примера к № 2.

Кроме того, $M(\varepsilon) = E$, следовательно, $$M(\varphi)M(\psi) = M(\varepsilon)\ \text{и}\ M(\psi)M(\varphi) = M(\varepsilon).$$

$M(\varepsilon) = E$: $\varepsilon(\boldsymbol{e}_k) = \boldsymbol{e}_k$, координатный столбец $\boldsymbol{e}_k$ — $k$-й столбец единичной матрицы. Затем в равенства $M(\varphi)B = E$, $BM(\varphi) = E$ из № 21 подставлены $B = M(\psi)$ (правильный смысл № 22) и $E = M(\varepsilon)$.

В силу теоремы 3.3 $M(\varphi)M(\psi) = M(\varphi\psi)$ и $M(\psi)M(\varphi) = M(\psi\varphi)$, поэтому $$M(\varphi\psi) = M(\varepsilon),\ \ M(\psi\varphi) = M(\varepsilon).$$

Проверка. $M(\varphi)M(\psi) = \begin{bmatrix}2 & 1\\ 1 & 1\end{bmatrix}\begin{bmatrix}1 & -1\\ -1 & 2\end{bmatrix} = \begin{bmatrix}1 & 0\\ 0 & 1\end{bmatrix}$, и в другом порядке — тоже $E$.

Это ровно условия (1): $\varphi$ обратим, и $\varphi^{-1} = \psi$. Круг замкнут: (f) ⇒ (a), и все шесть условий равносильны.

Полная линейная группа

Полная линейная группа.

Согласно теореме 5.1, множество всех обратимых $n \times n$-матриц над полем $\mathscr{F}$ есть группа относительно операций умножения и образования обратного элемента.

Напоминание из главы 6 (): там множество обратимых $n \times n$-матриц обозначено $GL(n, \mathscr{F})$ и доказано, что алгебра $\langle GL(n, \mathscr{F}), \cdot, {}^{-1}\rangle$ — группа. Проверка коротка: произведение обратимых матриц обратимо ($(AB)^{-1} = B^{-1}A^{-1}$), обратная к обратимой обратима, умножение матриц ассоциативно, $E$ — единица. Обе операции названы явно — «умножение» (бинарная) и «образование обратного» (унарная): у Куликова группа — алгебра с двумя главными операциями ().

Ссылка «согласно теореме 5.1» неверна (как и в № 20): нужный факт — теорема 2.2 главы 6, «Алгебра $\langle GL(n, \mathscr{F}), \cdot, {}^{-1}\rangle$ есть группа» (теорема 6.2.2, ).

ОПРЕДЕЛЕНИЕ. Мультипликативная группа всех обратимых $n \times n$-матриц над полем $\mathscr{F}$ называется полной линейной группой степени $n$ над полем $\mathscr{F}$ и обозначается $GL(n, \mathscr{F})$.

По косточкам.

  • «мультипликативная» — групповая операция записана как умножение (матриц), а не как сложение;
  • «полной линейной» — по-английски general linear group, отсюда буквы $GL$; «полная» — берутся все обратимые матрицы, а не подгруппа (например, не только с определителем $1$);
  • «степени $n$» — размер матриц $n \times n$; «над полем $\mathscr{F}$» — элементы матриц из $F$;
  • одно и то же обозначение $GL(n, \mathscr{F})$ служит и для множества, и для группы — книга различает их по контексту.

(а) На числах. $GL(1, \mathscr{R})$ — ненулевые действительные числа с умножением. $GL(2, \mathbf{Z}_2)$ состоит из $6$ матриц (из $16$ матриц $2 \times 2$ над $\mathbf{Z}_2$ определитель $\ne 0$ у шести) и изоморфна группе подстановок $S_3$; $|GL(2, \mathbf{Z}_3)| = (9 - 1)(9 - 3) = 48$, а в общем случае $|GL(n, \mathbf{Z}_p)| = (p^n - 1)(p^n - p)\cdots(p^n - p^{n-1})$ — первую строку выбираем ненулевой, каждую следующую — вне линейной оболочки предыдущих. Числа $6$ и $48$ проверены перебором.

(б) Из жизни. Все способы «перекодировать» сигнал из $n$ каналов линейно и без потерь (так, чтобы можно было раскодировать) образуют $GL(n, \mathscr{R})$.

(в) В программировании. Матрицы преобразований в компьютерной графике (поворот, масштаб, сдвиг экрана) — элементы $GL(2, \mathscr{R})$ и $GL(3, \mathscr{R})$; в криптографии шифр Хилла использует матрицы из $GL(n, \mathbf{Z}_{26})$ — точнее, обратимые по модулю $26$.

Все $2 \times 2$-матрицы над $\mathscr{R}$ с умножением — не группа: у $\begin{bmatrix}1 & 2\\ 2 & 4\end{bmatrix}$ нет обратной. Обратимые матрицы со сложением — тоже не группа: $E + (-E) = 0$ необратима, множество не замкнуто. И $GL(2, \mathscr{R})$ некоммутативна: $\begin{bmatrix}1 & 1\\ 0 & 1\end{bmatrix}\begin{bmatrix}1 & 0\\ 1 & 1\end{bmatrix} = \begin{bmatrix}2 & 1\\ 1 & 1\end{bmatrix}$, а в обратном порядке $\begin{bmatrix}1 & 1\\ 1 & 2\end{bmatrix}$.

В слове «Мультипликативная» вторая «и» пропечатана не полностью (без диагонального штриха, похожа на «н»), в слове «ОПРЕДЕЛЕНИЕ» не до конца пропечатана вторая «Е», союз «и» перед «обозначается» тоже без диагонали и похож на «н». В цитате буквы восстановлены.

Легко видеть, что любой обратимый оператор векторного пространства $\mathscr{V}$ есть автоморфизм этого пространства.

Автоморфизм векторного пространства — изоморфизм пространства на себя (, ): инъективное отображение $\mathscr{V}$ на $\mathscr{V}$, сохраняющее сложение и умножение на скаляры. Обратимый оператор линеен по определению, а по шагу (a) ⇒ (b) доказательства теоремы 4.1 (№ 9–№ 12) он инъективен и «на» — конечномерность там не использовалась. Это и есть упражнение 3 (№ 51).

Обратно: любой автоморфизм пространства $\mathscr{V}$ есть обратимый оператор.

Автоморфизм $f$ — биекция, поэтому у неё есть обратная функция $f^{-1}$ с $ff^{-1} = f^{-1}f = \varepsilon$ (). Остаётся линейность $f^{-1}$: обратное к изоморфизму — изоморфизм (свойство из ; прямая выкладка — в разборе № 2). Итог двух предложений: обратимые операторы — в точности автоморфизмы; отсюда обозначение в следующем предложении.

Множество всех обратимых операторов векторного пространства $\mathscr{V}$ обозначается $\mathrm{Aut}\,\mathscr{V}$.

$\mathrm{Aut}$ — от «automorphism». Это подмножество $\mathrm{Hom}(\mathscr{V}, \mathscr{V})$. Пример: для $\mathscr{V} = \mathbf{Z}_2^2$ всех операторов $16$ (по одному на матрицу, теорема 2.1), а в $\mathrm{Aut}\,\mathscr{V}$ — $6$. Для $\mathscr{V} = \mathscr{R}^1$ операторы — умножения $x \mapsto \lambda x$, и $\mathrm{Aut}\,\mathscr{V}$ — те, у которых $\lambda \ne 0$.

Заметьте: $\mathrm{Aut}\,\mathscr{V}$ — не подпространство $\mathscr{H}\mathit{om}(\mathscr{V}, \mathscr{V})$: в нём нет нулевого оператора, и сумма обратимых может быть необратимой ($\varepsilon + (-\varepsilon) = 0$).

Рассмотрим алгебру $\langle\mathrm{Aut}\,\mathscr{V},\ \cdot,\ {}^{-1}\rangle$, где $\cdot$ есть бинарная операция умножения линейных операторов пространства $\mathscr{V}$ и ${}^{-1}$ есть операция образования оператора, обратного к данному оператору; эту алгебру будем обозначать символом $\mathscr{A}\mathit{ut}\,\mathscr{V}$.

Множество $\mathrm{Aut}\,\mathscr{V}$ снабжается двумя операциями — так у Куликова устроена любая группа (): бинарная «$\cdot$» — композиция $\varphi\psi$, унарная «${}^{-1}$» — $\varphi \mapsto \varphi^{-1}$. Чтобы это была алгебра, операции должны не выводить из $\mathrm{Aut}\,\mathscr{V}$; это проверяется в начале доказательства теоремы 4.2 (№ 34–№ 36).

Различие шрифтов, как всюду в книге: прямое $\mathrm{Aut}\,\mathscr{V}$ — множество, рукописное $\mathscr{A}\mathit{ut}\,\mathscr{V}$ — алгебра на нём (ср. $V$ и $\mathscr{V}$, $\mathrm{Hom}$ и $\mathscr{H}\mathit{om}$).

ТЕОРЕМА 4.2. Пусть $\mathscr{V}$ — векторное пространство над полем $\mathscr{F}$.

Посылка: пространство любое — конечномерность не требуется (в отличие от теорем 4.1 и 4.3). Доказательство пользуется только определением обратимости.

Тогда алгебра $\mathscr{A}\mathit{ut}\,\mathscr{V}$ есть группа.

По косточкам. Группа () — алгебра $\langle G, \cdot, {}^{-1}\rangle$, в которой умножение ассоциативно, есть нейтральный элемент $e$ и $aa^{-1} = a^{-1}a = e$. Здесь $e = \varepsilon$. Группу $\mathscr{A}\mathit{ut}\,\mathscr{V}$ называют группой автоморфизмов (automorphism group) пространства, а также полной линейной группой пространства, $GL(\mathscr{V})$.

(а) На числах. $\mathscr{A}\mathit{ut}\,\mathbf{Z}_2^2$ — $6$ операторов; например, оператор $(x_1, x_2) \mapsto (x_2, x_1)$ сам себе обратный, а $(x_1, x_2) \mapsto (x_1 + x_2, x_1)$ имеет порядок $3$: применённый трижды, он даёт $\varepsilon$.

(б) Из жизни. Все обратимые линейные преобразования экрана (повороты, отражения, растяжения, сдвиги) можно комбинировать и отменять — это и есть групповые свойства.

(в) В программировании. В графических библиотеках трансформации хранят как матрицы и составляют умножением; метод «invert» есть у каждой невырожденной трансформации, а у вырожденной (масштаб $0$) — бросает ошибку: она вне группы.

Все линейные операторы с умножением не образуют группу: у нулевого оператора и у проекции нет обратных. А $\mathrm{Aut}\,\mathscr{V}$ со сложением не алгебра: сумма $\varepsilon + (-\varepsilon) = 0$ не обратима.

Доказательство. Множество $\mathrm{Aut}\,\mathscr{V}$ обратимых операторов пространства $\mathscr{V}$ замкнуто относительно операций $\cdot$ и ${}^{-1}$.

Первое, что нужно: $\langle\mathrm{Aut}\,\mathscr{V}, \cdot, {}^{-1}\rangle$ — действительно алгебра, т. е. обе операции не выводят из множества. Это утверждение; доказывается в двух следующих предложениях — отдельно для ${}^{-1}$ и для $\cdot$.

Действительно, если $\varphi$ — обратимый оператор, то $\varphi^{-1}$ есть обратимый оператор, так как $\varphi\varphi^{-1} = \varphi^{-1}\varphi = \varepsilon$.

Те же два равенства, прочитанные «с другой стороны»: для оператора $\varphi^{-1}$ роль обратного играет $\varphi$. Условия (1) симметричны, поэтому $\varphi^{-1} \in \mathrm{Aut}\,\mathscr{V}$ и $(\varphi^{-1})^{-1} = \varphi$.

Знак «=» повторён на переносе строки; в цитате он дан один раз.

Кроме того, если $\varphi$ и $\psi$ — обратимые операторы, то их произведение есть обратимый линейный оператор, так как $$(\varphi\psi)(\psi^{-1}\varphi^{-1}) = \varepsilon\ \text{и}\ (\psi^{-1}\varphi^{-1})(\varphi\psi) = \varepsilon.$$

Произведение линейных операторов линейно (предложение 3.1, ). Кандидат в обратный — $\psi^{-1}\varphi^{-1}$, сомножители в обратном порядке. Проверка по ассоциативности: $(\varphi\psi)(\psi^{-1}\varphi^{-1}) = \varphi(\psi\psi^{-1})\varphi^{-1} = \varphi\varepsilon\varphi^{-1} = \varphi\varphi^{-1} = \varepsilon$, и так же в другом порядке. Это упражнение 1 (№ 49).

Образ. Утром надевают носки, потом ботинки; вечером снимают сначала ботинки, потом носки. «Отмена» цепочки идёт в обратном порядке.

$(\varphi\psi)^{-1} \ne \varphi^{-1}\psi^{-1}$ в общем случае: для $A = \begin{bmatrix}1 & 1\\ 0 & 1\end{bmatrix}$, $B = \begin{bmatrix}1 & 0\\ 1 & 1\end{bmatrix}$ $(AB)^{-1} = \begin{bmatrix}1 & -1\\ -1 & 2\end{bmatrix} = B^{-1}A^{-1}$, а $A^{-1}B^{-1} = \begin{bmatrix}2 & -1\\ -1 & 1\end{bmatrix}$.

Произведение обратимых операторов и его обратный. Для $\varphi$ и для $\psi$ выберите оператор кнопками «поворот» (на $90^\circ$), «сдвиг», «растяжение» (вдвое по $x_1$), «отражение» (относительно оси $x_1$). Кнопка «шаг» проводит единичный квадрат (пунктир) по цепочке: квадрат → $\psi$ → $\varphi$ (это $(\varphi\psi)(\text{квадрат})$, так как у Куликова $(\varphi\psi)(\boldsymbol{x}) = \varphi(\psi(\boldsymbol{x}))$) → $\varphi^{-1}$ → $\psi^{-1}$ — и квадрат возвращается на место: $(\varphi\psi)^{-1} = \psi^{-1}\varphi^{-1}$. Закрашен текущий образ квадрата, тонкий контур — образ на предыдущем шаге, синяя и оранжевая стрелки — образы $\boldsymbol{e}_1$ и $\boldsymbol{e}_2$. Кнопка «сначала» возвращает к началу. Флажок «сравнить с $\psi\varphi$» рисует оранжевым пунктиром образ квадрата при $\psi\varphi$; табло показывает по строкам матрицы $M(\varphi\psi) = M(\varphi)M(\psi)$ и $M(\psi\varphi)$ — обычно они разные.

Согласно теореме 2.3, умножение линейных операторов ассоциативно.

Первая аксиома группы. Умножение операторов — композиция отображений, а композиция функций ассоциативна: $\varphi(\psi\chi) = (\varphi\psi)\chi$, обе части переводят $\boldsymbol{x}$ в $\varphi(\psi(\chi(\boldsymbol{x})))$.

Ссылка неверна: теорема 2.3 главы 8 — о координатных столбцах, $M(\varphi(\boldsymbol{x})) = M(\varphi)M(\boldsymbol{x})$ (); ассоциативность там не доказывается. Ассоциативность композиции функций — теорема 3.5 главы 2, «Композиция функций обладает свойством ассоциативности» (теорема 2.3.5, ); по-видимому, в номере «2.3.5» выпала последняя цифра.

Тождественный оператор $\varepsilon$ обратим и является нейтральным элементом относительно умножения, т. е. $\varphi\varepsilon = \varepsilon\varphi = \varphi$ для любого линейного оператора $\varphi$.

Вторая аксиома. $\varepsilon \in \mathrm{Aut}\,\mathscr{V}$, так как $\varepsilon\varepsilon = \varepsilon$ — он сам себе обратный. Нейтральность: $(\varphi\varepsilon)(\boldsymbol{x}) = \varphi(\varepsilon(\boldsymbol{x})) = \varphi(\boldsymbol{x})$ и $(\varepsilon\varphi)(\boldsymbol{x}) = \varepsilon(\varphi(\boldsymbol{x})) = \varphi(\boldsymbol{x})$. В матрицах — $AE = EA = A$.

Наконец, для любого обратимого оператора $\varphi$ выполняются равенства $\varphi\varphi^{-1} = \varphi^{-1}\varphi = \varepsilon$.

Третья аксиома — по самому определению $\varphi^{-1}$ (условия (1)). Унарная операция группы — именно «${}^{-1}$», поэтому аксиома записана через неё.

Таким образом, главные операции алгебры $\mathscr{A}\mathit{ut}\,\mathscr{V}$ удовлетворяют всем групповым аксиомам.

Сводка: замкнутость (№ 35, № 36), ассоциативность (№ 37), нейтральный элемент (№ 38), обратные (№ 39). «Главные операции» — те, что перечислены в записи алгебры: $\cdot$ и ${}^{-1}$.

Следовательно, эта алгебра является группой. $\square$

Вывод по определению группы. Группа некоммутативна уже при $\dim\mathscr{V} = 2$ (пример в разборе № 27 и рисунок 2); при $\dim\mathscr{V} = 1$ она коммутативна — это мультипликативная группа поля: $\mathscr{A}\mathit{ut}\,\mathscr{V} \cong \langle F\backslash\{0\}, \cdot, {}^{-1}\rangle$.

ТЕОРЕМА 4.3. Пусть $\mathscr{V}$ есть $n$-мерное ненулевое векторное пространство над полем $\mathscr{F}$.

Посылка: $\dim\mathscr{V} = n \geqslant 1$ — нужен базис, чтобы говорить о матрицах операторов.

Тогда группа $\mathscr{A}\mathit{ut}\,\mathscr{V}$ изоморфна полной линейной матричной группе $GL(n, \mathscr{F})$.

По косточкам. «Изоморфна» — существует биекция, сохраняющая главные операции групп (); значит, с точки зрения алгебры группа обратимых операторов и группа обратимых матриц — одно и то же. «Полной линейной матричной» — это $GL(n, \mathscr{F})$ из определения (№ 27). Теорема — групповой «двойник» теоремы 3.3 (изоморфизм алгебр $\mathit{End}\,\mathscr{V} \cong \mathfrak{M}(n, \mathscr{F})$): ограничиваемся обратимыми элементами.

(а) На числах. Поворот $\rho$ плоскости на $90^\circ$ ↔ $\begin{bmatrix}0 & -1\\ 1 & 0\end{bmatrix}$; $\rho^2$ (поворот на $180^\circ$) ↔ квадрат этой матрицы $-E$; $\rho^{-1}$ ↔ обратная $\begin{bmatrix}0 & 1\\ -1 & 0\end{bmatrix}$. $|\mathrm{Aut}\,\mathbf{Z}_2^2| = |GL(2, \mathbf{Z}_2)| = 6$.

(б) Из жизни. Последовательность движений робота-манипулятора можно описывать словами («повернуть, растянуть») или матрицами — и складывать их цепочки перемножением матриц: результат одинаков.

(в) В программировании. Поэтому код хранит преобразование как массив (n, n): композиция — A @ B, обратное — np.linalg.inv(A). Важно помнить порядок: «сначала B, потом A» — это A @ B.

Изоморфизм зависит от выбора базиса, но сама изоморфность — нет. Без условия «$n$-мерное» утверждение теряет смысл: группа автоморфизмов пространства всех многочленов не изоморфна ни одной $GL(n, \mathscr{F})$ — хотя бы потому, что при $\mathscr{F} = \mathbf{Z}_2$ она бесконечна, а $GL(n, \mathbf{Z}_2)$ конечны.

Доказательство. Рассмотрим биективное отображение $$\Phi\colon \mathrm{Aut}\,\mathscr{V} \to \mathrm{GL}\,(n,\mathscr{F}),$$ определяемое равенством $\Phi(\varphi) = M(\varphi)$, где $M(\varphi)$ — матрица линейного оператора $\varphi$ относительно фиксированного базиса пространства $\mathscr{V}$.

Почему $\Phi$ определено и биективно — книга говорит «биективное» без пояснения. Обоснование:

  • $\Phi$ действует в $GL(n, \mathscr{F})$: если $\varphi$ обратим, то $M(\varphi)$ обратима — теорема 4.1, (a) ⇒ (f);
  • инъективно: $\varphi \mapsto M(\varphi)$ инъективно на всех операторах (теорема 2.1), тем более на обратимых;
  • «на»: для $A \in GL(n, \mathscr{F})$ по теореме 2.1 есть оператор $\varphi$ с $M(\varphi) = A$, а по теореме 4.1, (f) ⇒ (a), он обратим, т. е. $\varphi \in \mathrm{Aut}\,\mathscr{V}$.

Итак, $\Phi$ — ограничение биекции из теоремы 2.1 на $\mathrm{Aut}\,\mathscr{V}$, и оно биективно на $GL(n, \mathscr{F})$.

В выключной формуле $\mathrm{GL}$ набрано прямым шрифтом и после запятой в «$(n,\mathscr{F})$» нет пробела, тогда как в остальном параграфе — курсивное $GL(n, \mathscr{F})$. Обозначение то же; в цитате — как напечатано.

Согласно теореме 3.3, для любых $\varphi, \psi \in \mathrm{Aut}\,\mathscr{V}$ $$M(\varphi\psi) = M(\varphi)M(\psi).$$

Теорема 3.3 () верна для любых операторов, значит, и для обратимых. Проверка: $\rho$ — поворот на $90^\circ$, $\sigma(x_1, x_2) = (x_1 + x_2, x_2)$; $(\rho\sigma)(x_1, x_2) = \rho(x_1 + x_2, x_2) = (-x_2, x_1 + x_2)$, матрица $\begin{bmatrix}0 & -1\\ 1 & 1\end{bmatrix}$, и $\begin{bmatrix}0 & -1\\ 1 & 0\end{bmatrix}\begin{bmatrix}1 & 1\\ 0 & 1\end{bmatrix} = \begin{bmatrix}0 & -1\\ 1 & 1\end{bmatrix}$.

Следовательно, для любых обратимых операторов $\varphi$, $\psi$ имеем $\Phi(\varphi\psi) = \Phi(\varphi)\Phi(\psi)$.

То же равенство в обозначениях $\Phi$: $\Phi$ сохраняет бинарную операцию. $\varphi\psi \in \mathrm{Aut}\,\mathscr{V}$ по № 36, так что левая часть определена.

По теореме 3.3.1, отсюда следует, что $\Phi$ есть гомоморфизм.

Теорема 3.1 главы 3 (): отображение группы в группу, сохраняющее бинарную операцию, переводит единицу в единицу и является гомоморфизмом — т. е. сохраняет и унарную операцию: $\Phi(\varphi^{-1}) = \Phi(\varphi)^{-1}$. Проверять отдельно $M(\varphi^{-1}) = M(\varphi)^{-1}$ не нужно (хотя это и так видно из доказательства теоремы 4.1, № 25). Ссылка в книге верна.

Следовательно, $\Phi$ есть изоморфизм группы $\mathscr{A}\mathit{ut}\,\mathscr{V}$ на группу $GL(n, \mathscr{F})$. $\square$

Изоморфизм групп — биективный (инъективный и «на») гомоморфизм. Биективность — № 44, гомоморфизм — № 47. Теорема доказана.

Упражнения

Упражнения

1. Пусть $\varphi$, $\psi$ — обратимые линейные операторы векторного пространства. Докажите, что $\varphi\psi$ есть обратимый линейный оператор и $(\varphi\psi)^{-1} = \psi^{-1}\varphi^{-1}$.

Решение. $\varphi\psi$ линеен (предложение 3.1). Положим $\chi = \psi^{-1}\varphi^{-1}$. По ассоциативности $(\varphi\psi)\chi = \varphi(\psi\psi^{-1})\varphi^{-1} = \varphi\varepsilon\varphi^{-1} = \varphi\varphi^{-1} = \varepsilon$ и $\chi(\varphi\psi) = \psi^{-1}(\varphi^{-1}\varphi)\psi = \psi^{-1}\varepsilon\psi = \psi^{-1}\psi = \varepsilon$. Значит, $\chi$ удовлетворяет условиям (1) для $\varphi\psi$: $\varphi\psi$ обратим, и по единственности обратного (№ 4) $(\varphi\psi)^{-1} = \chi = \psi^{-1}\varphi^{-1}$. Конечномерность не нужна.

Проверка. $A = \begin{bmatrix}1 & 1\\ 0 & 1\end{bmatrix}$, $B = \begin{bmatrix}1 & 0\\ 1 & 1\end{bmatrix}$: $AB = \begin{bmatrix}2 & 1\\ 1 & 1\end{bmatrix}$, $(AB)^{-1} = \begin{bmatrix}1 & -1\\ -1 & 2\end{bmatrix}$, $B^{-1}A^{-1} = \begin{bmatrix}1 & 0\\ -1 & 1\end{bmatrix}\begin{bmatrix}1 & -1\\ 0 & 1\end{bmatrix} = \begin{bmatrix}1 & -1\\ -1 & 2\end{bmatrix}$ — совпало (проверено и программой).

2. Покажите, что линейные операторы $\varphi$, $\psi$ векторного пространства обратимы тогда и только тогда, когда обратимы операторы $\varphi\psi$ и $\psi\varphi$.

Решение. «Только тогда»: если $\varphi$, $\psi$ обратимы, то $\varphi\psi$ и $\psi\varphi$ обратимы по упражнению 1.

«Тогда»: пусть $\alpha = (\varphi\psi)^{-1}$, $\beta = (\psi\varphi)^{-1}$. Из $\varphi(\psi\alpha) = (\varphi\psi)\alpha = \varepsilon$ — у $\varphi$ есть правый обратный $\psi\alpha$; из $(\beta\psi)\varphi = \beta(\psi\varphi) = \varepsilon$ — левый обратный $\beta\psi$. По выкладке из № 4 левый и правый обратные совпадают: $\beta\psi = (\beta\psi)\varepsilon = (\beta\psi)(\varphi\psi\alpha) = ((\beta\psi)\varphi)(\psi\alpha) = \psi\alpha$. Значит, $\psi\alpha$ — двусторонний обратный, $\varphi$ обратим. Для $\psi$ то же: $\psi(\varphi\beta) = \varepsilon$ и $(\alpha\varphi)\psi = \varepsilon$. Конечномерность не используется.

Обратимости одного $\varphi\psi$ мало, если пространство бесконечномерно: на многочленах $DJ = \varepsilon$ обратим, а $D$ и $J$ — нет (разбор № 2). В конечномерном пространстве одного достаточно — см. упражнение 4.

3. Пусть $\varphi$ — обратимый оператор векторного пространства $\mathscr{V}$. Покажите, что $\varphi$ есть изоморфизм $\mathscr{V}$ на $\mathscr{V}$.

Решение. Изоморфизм векторных пространств () — инъективное отображение «на», сохраняющее сложение и умножение на скаляры. Сохранение операций — это линейность $\varphi$ (обратимый оператор по определению линейный). Инъективность и «на» доказаны в шаге (a) ⇒ (b) теоремы 4.1 (№ 9–№ 12); там не использовалась конечномерность, поэтому вывод верен для любого $\mathscr{V}$. Это и утверждение № 28.

4. Пусть $\varphi$, $\psi$ — линейные операторы конечномерного векторного пространства $\mathscr{V}$. Покажите, что если $\varphi\psi$ есть тождественный оператор пространства $\mathscr{V}$, то $\varphi$ и $\psi$ обратимы.

Решение. Если $\mathscr{V}$ нулевое, единственный оператор — $\varepsilon$, он обратим. Пусть $\mathscr{V}$ ненулевое. $\psi$ инъективен: из $\psi(\boldsymbol{a}) = \psi(\boldsymbol{b})$ следует $\boldsymbol{a} = \varphi\psi(\boldsymbol{a}) = \varphi\psi(\boldsymbol{b}) = \boldsymbol{b}$. Значит, $\mathrm{Ker}\,\psi = \{\mathbf{0}\}$, и по теореме 4.1, (c) ⇒ (a), $\psi$ обратим. Тогда $\varphi = \varphi\varepsilon = \varphi(\psi\psi^{-1}) = (\varphi\psi)\psi^{-1} = \psi^{-1}$ — обратим как обратный к обратимому, и $\varphi^{-1} = \psi$.

Итог: в конечномерном пространстве одностороннего обратного достаточно; другая сторона получается сама. В матрицах: из $AB = E$ следует $BA = E$.

Контрпример — те же $D$ (производная) и $J$ (интеграл $\int_0^x$) на пространстве всех многочленов: $DJ = \varepsilon$, но $D$ и $J$ необратимы.

5. Пусть $\varphi$, $\psi$ — линейные операторы векторного пространства. Покажите, что если $\mathrm{Ker}\,\varphi = \mathrm{Ker}\,\psi = \{0\}$, то $\mathrm{Ker}\,(\varphi\psi) = \{0\}$.

Решение. Пусть $(\varphi\psi)(\boldsymbol{x}) = \mathbf{0}$, т. е. $\varphi(\psi(\boldsymbol{x})) = \mathbf{0}$. Тогда $\psi(\boldsymbol{x}) \in \mathrm{Ker}\,\varphi = \{\mathbf{0}\}$, т. е. $\psi(\boldsymbol{x}) = \mathbf{0}$, откуда $\boldsymbol{x} \in \mathrm{Ker}\,\psi = \{\mathbf{0}\}$. Значит, $\mathrm{Ker}\,(\varphi\psi) = \{\mathbf{0}\}$ ($\mathbf{0}$ в ядре всегда лежит). На языке функций: композиция инъекций — инъекция (теорема 3.9 главы 2, ). Конечномерность не нужна.

Проверка. На многочленах $J$ инъективен, $J^2(p) = \int_0^x\!\int_0^t p$ — тоже: $J^2(p) = 0$ только при $p = 0$.

В упражнениях (мелкий шрифт) нуль в $\{0\}$ набран светлым, хотя это нулевой вектор; в теореме 4.1 и её доказательстве — полужирный $\{\mathbf{0}\}$. В цитате — как напечатано. По содержанию это упражнение повторяет упражнение 9 § 1 (), сформулированное там иначе.

6. Пусть $\varphi$ есть линейное отображение векторного пространства $\mathscr{U}$ в векторное пространство $\mathscr{V}$ и $\psi$ — линейное отображение $\mathscr{V}$ в векторное пространство $\mathscr{W}$. Докажите, что если $\mathrm{Ker}\,\varphi = \{0\}$ и $\mathrm{Ker}\,\psi = \{0'\}$, то $\mathrm{Ker}\,(\psi\varphi) = \{0\}$.

Смысл обозначений. Теперь три разных пространства: $\varphi\colon \mathscr{U} \to \mathscr{V}$, $\psi\colon \mathscr{V} \to \mathscr{W}$, произведение $\psi\varphi\colon \mathscr{U} \to \mathscr{W}$, $(\psi\varphi)(\boldsymbol{x}) = \psi(\varphi(\boldsymbol{x}))$. Ядро $\varphi$ лежит в $U$, поэтому $0$ — нулевой вектор $\mathscr{U}$; ядро $\psi$ лежит в $V$, и его нуль — нулевой вектор $\mathscr{V}$, обозначенный $0'$, чтобы не путать. Ядро $\psi\varphi$ снова в $U$.

Решение. Если $\psi(\varphi(\boldsymbol{x}))$ — нулевой вектор $\mathscr{W}$, то $\varphi(\boldsymbol{x}) \in \mathrm{Ker}\,\psi = \{0'\}$, т. е. $\varphi(\boldsymbol{x}) = 0'$, откуда $\boldsymbol{x} \in \mathrm{Ker}\,\varphi = \{0\}$. Итак, $\mathrm{Ker}\,(\psi\varphi) = \{0\}$ — то же рассуждение, что в упражнении 5, но с аккуратным учётом, где какой нуль.

Пример. $\varphi\colon \mathscr{R}^1 \to \mathscr{R}^2$, $x \mapsto (x, 2x)$; $\psi\colon \mathscr{R}^2 \to \mathscr{R}^3$, $(y_1, y_2) \mapsto (y_1, y_2, y_1 + y_2)$; оба с нулевым ядром, $\psi\varphi(x) = (x, 2x, 3x)$ — нуль только при $x = 0$.

Знак «=» в «$\mathrm{Ker}\,\psi = \{0'\}$» повторён на переносе строки; в цитате он дан один раз. Нули, как и в упражнении 5, светлые.

7. Пусть $\varphi$ — обратимый и $\psi$ — произвольный линейный оператор конечномерного векторного пространства. Покажите, что $\text{ранг}\,(\varphi\psi) = \text{ранг}\,(\psi\varphi) = \text{ранг}\,\psi$.

Решение. Ранг — размерность образа.

  • $\mathrm{Im}\,(\psi\varphi) = \psi(\varphi(V)) = \psi(V) = \mathrm{Im}\,\psi$, так как $\varphi$ — отображение «на» ($\varphi(V) = V$, теорема 4.1). Значит, $\text{ранг}\,(\psi\varphi) = \text{ранг}\,\psi$.
  • $\mathrm{Im}\,(\varphi\psi) = \varphi(\mathrm{Im}\,\psi)$. Ограничение $\varphi$ на подпространство $\mathscr{I}\mathit{m}\,\psi$ — инъективное линейное отображение этого подпространства на $\varphi(\mathrm{Im}\,\psi)$, т. е. изоморфизм; изоморфные пространства имеют равные размерности (). Конкретно: если $\boldsymbol{b}_1, \ldots, \boldsymbol{b}_r$ — базис $\mathscr{I}\mathit{m}\,\psi$, то $\varphi(\boldsymbol{b}_1), \ldots, \varphi(\boldsymbol{b}_r)$ порождают $\varphi(\mathrm{Im}\,\psi)$ и линейно независимы (из $\sum\lambda_i\varphi(\boldsymbol{b}_i) = \mathbf{0}$ следует $\sum\lambda_i\boldsymbol{b}_i \in \mathrm{Ker}\,\varphi = \{\mathbf{0}\}$). Значит, $\text{ранг}\,(\varphi\psi) = r = \text{ранг}\,\psi$.

В матрицах: умножение на обратимую матрицу слева или справа не меняет ранга. Проверка (программой): $M(\varphi) = \begin{bmatrix}2 & 1\\ 1 & 1\end{bmatrix}$, $M(\psi) = \begin{bmatrix}1 & 2\\ 2 & 4\end{bmatrix}$ — ранги $M(\varphi)M(\psi)$, $M(\psi)M(\varphi)$ и $M(\psi)$ все равны $1$. То же утверждение — упражнение 6 § 2 ().

Знак «=» после «ранг $(\varphi\psi)$» повторён на переносе строки; в цитате он дан один раз.

8. Докажите, что линейный оператор конечномерного векторного пространства $\mathscr{V}$ обратим тогда и только тогда, когда он каждую линейно независимую систему векторов пространства $\mathscr{V}$ переводит в линейно независимую систему векторов этого пространства.

Решение. «Только тогда»: пусть $\varphi$ обратим и $\boldsymbol{a}_1, \ldots, \boldsymbol{a}_m$ линейно независимы. Если $\lambda_1\varphi(\boldsymbol{a}_1) + \ldots + \lambda_m\varphi(\boldsymbol{a}_m) = \mathbf{0}$, то по линейности $\varphi(\lambda_1\boldsymbol{a}_1 + \ldots + \lambda_m\boldsymbol{a}_m) = \mathbf{0}$, т. е. $\lambda_1\boldsymbol{a}_1 + \ldots + \lambda_m\boldsymbol{a}_m \in \mathrm{Ker}\,\varphi = \{\mathbf{0}\}$, и все $\lambda_i = 0$. Значит, $\varphi(\boldsymbol{a}_1), \ldots, \varphi(\boldsymbol{a}_m)$ независимы.

«Тогда»: если $\mathscr{V}$ нулевое, $\varphi = \varepsilon$ обратим. Иначе возьмём любой $\boldsymbol{a} \ne \mathbf{0}$: система из одного вектора $\boldsymbol{a}$ независима, значит, независима и система $\varphi(\boldsymbol{a})$, т. е. $\varphi(\boldsymbol{a}) \ne \mathbf{0}$. Следовательно, $\mathrm{Ker}\,\varphi = \{\mathbf{0}\}$, и по теореме 4.1 $\varphi$ обратим. (Другой путь: образ базиса — $n$ независимых векторов, ранг $\varphi = n$, условие (e).)

Пример. Проекция $(x_1, x_2) \mapsto (x_1, 0)$ переводит независимые $(1, 0)$, $(0, 1)$ в зависимые $(1, 0)$, $\mathbf{0}$ — и необратима.

На пространстве многочленов $J(p) = \int_0^x p$ переводит независимые системы в независимые (у него нулевое ядро), но не обратим. Шаг «тогда» опирается на теорему 4.1.

9. Пусть $\mathscr{H}\mathit{om}(\mathscr{V}, \mathscr{V})$ есть векторное пространство всех линейных операторов пространства $\mathscr{V}$. Пусть $\varphi$ — фиксированный и $\psi$ — произвольный линейный оператор пространства $\mathscr{V}$. Докажите, что отображение $\psi \longmapsto \varphi\psi$ является линейным оператором пространства $\mathscr{H}\mathit{om}(\mathscr{V}, \mathscr{V})$. Покажите, что множество $\{\varphi\psi \mid \psi \in \mathrm{Hom}(\mathscr{V}, \mathscr{V})\}$ совпадает с множеством всех линейных операторов векторного пространства $\mathscr{H}\mathit{om}(\mathscr{V}, \mathscr{V})$, если $\varphi$ — обратимый оператор.

Смысл. Обозначим $L_\varphi(\psi) = \varphi\psi$ — «умножение слева на $\varphi$». Это отображение пространства операторов $\mathscr{H}\mathit{om}(\mathscr{V}, \mathscr{V})$ в себя; его аргументы и значения — сами операторы пространства $\mathscr{V}$.

Решение, часть 1. $L_\varphi$ линеен: $L_\varphi(\psi_1 + \psi_2) = \varphi(\psi_1 + \psi_2) = \varphi\psi_1 + \varphi\psi_2$ — условие билинейности (2) из § 3, $\chi(\varphi + \psi) = \chi\varphi + \chi\psi$ (); $L_\varphi(\lambda\psi) = \varphi(\lambda\psi) = \lambda(\varphi\psi)$ — условие (3) там же. Значения $\varphi\psi$ лежат в $\mathrm{Hom}(\mathscr{V}, \mathscr{V})$ по предложению 3.1.

Часть 2. Пусть $\varphi$ обратим. Включение $\{\varphi\psi\} \subset \mathrm{Hom}(\mathscr{V}, \mathscr{V})$ — из части 1. Обратно, любой оператор $\chi$ представим в виде $\chi = \varepsilon\chi = (\varphi\varphi^{-1})\chi = \varphi(\varphi^{-1}\chi)$, т. е. $\chi = L_\varphi(\psi)$ при $\psi = \varphi^{-1}\chi$. Значит, множество $\{\varphi\psi \mid \psi \in \mathrm{Hom}(\mathscr{V}, \mathscr{V})\}$ — это всё $\mathrm{Hom}(\mathscr{V}, \mathscr{V})$: $L_\varphi$ — отображение «на». Более того, $L_\varphi$ обратим: $L_{\varphi^{-1}}L_\varphi = L_\varphi L_{\varphi^{-1}} = \varepsilon$, т. е. $L_\varphi \in \mathrm{Aut}\,\mathscr{H}\mathit{om}(\mathscr{V}, \mathscr{V})$.

Обратно (не спрашивается, но полезно): если $\mathscr{V}$ конечномерно и $L_\varphi$ «на», то $\varepsilon = \varphi\psi$ для некоторого $\psi$, и по упражнению 4 $\varphi$ обратим.

Проверка в матрицах (программой): при $\dim\mathscr{V} = 2$ пространство $\mathscr{H}\mathit{om}$ четырёхмерно, и матрица $L_\varphi$ в базисе из матричных единиц $E_{11}, E_{21}, E_{12}, E_{22}$ — блочная $\begin{bmatrix}A & 0\\ 0 & A\end{bmatrix}$ (столбцы матрицы $\psi$ умножаются на $A = M(\varphi)$ независимо); для $A = \begin{bmatrix}2 & 1\\ 1 & 1\end{bmatrix}$ её определитель $(\det A)^2 = 1 \ne 0$.

Множество $\{\varphi\psi\}$ состоит из операторов пространства $\mathscr{V}$ — элементов пространства $\mathscr{H}\mathit{om}(\mathscr{V}, \mathscr{V})$, а не операторов этого пространства. Точная формулировка: «множество $\{\varphi\psi \mid \psi \in \mathrm{Hom}(\mathscr{V}, \mathscr{V})\}$ совпадает с множеством всех линейных операторов векторного пространства $\mathscr{V}$, т. е. с $\mathrm{Hom}(\mathscr{V}, \mathscr{V})$». Именно это и доказано выше.

Частые ошибки

В бесконечномерном пространстве — нет: $DJ = \varepsilon$, но ни $D$, ни $J$ не обратимы. В конечномерном — да (упражнение 4), но это теорема, а не определение.

Только для оператора конечномерного пространства (теорема 4.1) и только для отображения пространства в себя. Вложение $\mathscr{R}^2 \to \mathscr{R}^3$ и интеграл $J$ на многочленах имеют нулевое ядро, но необратимы.

Порядок меняется: $(\varphi\psi)^{-1} = \psi^{-1}\varphi^{-1}$. Совпадение с $\varphi^{-1}\psi^{-1}$ бывает лишь для перестановочных $\varphi$, $\psi$.

У Куликова $(\varphi\psi)(\boldsymbol{x}) = \varphi(\psi(\boldsymbol{x}))$ — сначала $\psi$. И $M(\varphi\psi) = M(\varphi)M(\psi)$ в том же порядке. Группа $GL(n, \mathscr{F})$ при $n \geqslant 2$ некоммутативна, порядок важен.

Нет: нулевой оператор необратим, сумма обратимых может быть необратимой. $\mathrm{Aut}\,\mathscr{V}$ замкнуто относительно умножения и обращения — это группа, а не векторное пространство.

Запись $\varphi^{-1}(\mathbf{0}) = \mathrm{Ker}\,\varphi$ из § 1 — полный прообраз множества, он есть у любого оператора. Оператор $\varphi^{-1}$ — только у обратимого.

Запятая вместо точки после формулы (1); пропущена скобка в «$\psi(\varphi(\boldsymbol{b})$»; «$B = M(\varphi)$» вместо $B = M(\psi)$; полужирное $\boldsymbol{\varepsilon}$ в конце доказательства теоремы 4.1; ссылки «теорема 5.1» (должно быть 6.2.8 и 6.2.2) и «теорема 2.3» (должно быть 2.3.5); в упражнении 9 «операторов пространства $\mathscr{H}\mathit{om}(\mathscr{V}, \mathscr{V})$» вместо «операторов пространства $\mathscr{V}$».

Итоги

  • Обратимый оператор: существует линейный $\psi$ с $\varphi\psi = \psi\varphi = \varepsilon$. Такой $\psi$ единственный — обратный $\varphi^{-1}$; любой левый обратный совпадает с любым правым.
  • Теорема 4.1 (конечномерное ненулевое $\mathscr{V}$): равносильны (a) $\varphi$ обратим; (b) $\varphi$ — биекция $V$ на $V$; (c) $\mathrm{Ker}\,\varphi = \{\mathbf{0}\}$; (d) дефект $0$; (e) ранг $= \dim\mathscr{V}$; (f) $M(\varphi)$ обратима (в любом базисе). Попутно $M(\varphi^{-1}) = M(\varphi)^{-1}$.
  • $GL(n, \mathscr{F})$ — полная линейная группа: все обратимые $n \times n$-матрицы с умножением; $|GL(2, \mathbf{Z}_2)| = 6$, при $n \geqslant 2$ некоммутативна.
  • Обратимые операторы — это автоморфизмы; их множество $\mathrm{Aut}\,\mathscr{V}$ с умножением и обращением — группа $\mathscr{A}\mathit{ut}\,\mathscr{V}$ (теорема 4.2, для любого $\mathscr{V}$); $(\varphi\psi)^{-1} = \psi^{-1}\varphi^{-1}$.
  • Теорема 4.3: при $\dim\mathscr{V} = n \geqslant 1$ отображение $\varphi \mapsto M(\varphi)$ — изоморфизм $\mathscr{A}\mathit{ut}\,\mathscr{V} \cong GL(n, \mathscr{F})$.
  • Упражнения: в конечномерном пространстве достаточно одностороннего обратного (4); обратимый оператор не меняет ранга при умножении (7) и сохраняет линейную независимость (8); умножение на обратимый $\varphi$ — автоморфизм пространства операторов (9).
